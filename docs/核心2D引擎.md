# cocos2d-x 3.0-oh 核心2D引擎

## 1. CCDirector - 导演类

**文件**: `cocos/2d/CCDirector.h`, 继承自 Ref

### 1.1 职责
- OpenGL 上下文初始化
- 场景管理（运行、切换、压栈、弹出）
- 主循环驱动
- 帧率控制
- 全局管理器持有（Scheduler, ActionManager, EventDispatcher, TextureCache, Renderer）

### 1.2 投影类型
```cpp
enum class Projection { _2D, _3D, CUSTOM, DEFAULT = _3D };
```

## 2. CCNode - 节点基类

**文件**: `cocos/2d/CCNode.h`, 继承自 Ref

### 2.1 核心属性
| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| position | Point | (0,0) | 位置（父坐标系） |
| scaleX/Y/Z | float | 1.0 | 缩放 |
| rotation | float | 0 | 旋转（度，顺时针） |
| skewX/Y | float | 0 | 倾斜 |
| anchorPoint | Point | (0.5,0.5) | 锚点（归一化） |
| contentSize | Size | (0,0) | 内容尺寸 |
| visible | bool | true | 可见性 |
| localZOrder | int | 0 | 本地Z序 |
| globalZOrder | float | 0 | 全局Z序 |
| tag | int | -1 | 标签 |
| opacity | GLubyte | 255 | 不透明度 |
| color | Color3B | (255,255,255) | 颜色 |

## 6. SpriteBatchNode - 精灵批处理节点

**文件**: `cocos/2d/CCSpriteBatchNode.h`, 继承自 Node, TextureProtocol

### 6.1 职责
- 将多个精灵合并为一次OpenGL绘制调用（批处理）
- 只能引用一个纹理，所有子精灵必须使用同一纹理
- 仅接受 Sprite 或其子类作为子节点

### 6.2 关键接口
```cpp
static SpriteBatchNode* create(const std::string& fileImage, ssize_t capacity = DEFAULT_CAPACITY);
static SpriteBatchNode* createWithTexture(Texture2D* tex, ssize_t capacity = DEFAULT_CAPACITY);
```

## 11. Protocols - 协议接口

**文件**: `cocos/2d/CCProtocols.h`

### 11.1 关键协议
- **__RGBAProtocol**: 颜色和透明度协议，提供 `setColor()`, `getColor()`, `setOpacity()`, `getOpacity()` 等接口
- **TextureProtocol**: 纹理协议，提供 `getTexture()`, `setTexture()` 接口
- **BlendProtocol**: 混合协议，提供 `setBlendFunc()`, `getBlendFunc()` 接口

## 12. 使用示例

auto scene = Scene::create();
