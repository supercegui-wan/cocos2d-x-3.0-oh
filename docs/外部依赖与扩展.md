## 4. 废弃兼容层 (deprecated/)

**文件位置**: `cocos/deprecated/`

### 4.1 废弃类型

| 旧类型 | 新类型 | 说明 |
|--------|--------|------|
| CCArray | Vector<Ref*> | 引用计数数组 |
| CCDictionary | Map<std::string, Ref*> | 引用计数字典 |
| CCString | std::string | 字符串 |
| CCBool | bool | 布尔值 |
| CCInteger | int | 整数 |
| CCFloat | float | 浮点数 |
| CCDouble | double | 双精度浮点 |
| CCSet | std::set<Ref*> | 集合 |

### 4.2 使用说明
```cpp
// 旧代码（兼容）
CCArray* array = CCArray::create();
array->addObject(sprite);

// 新代码（推荐）
Vector<Sprite*> sprites;
sprites.pushBack(sprite);
```
