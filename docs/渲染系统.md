# cocos2d-x 3.0-oh 渲染系统

## 1. 概述

**文件位置**: `cocos/2d/renderer/`, `cocos/2d/CCGLProgram.h`, `cocos/2d/CCShaderCache.h`, `cocos/2d/CCTexture2D.h`

### 1.1 渲染管线

```
Scene Graph (visit遍历)
    ↓
RenderCommand 队列 (QuadCommand, CustomCommand, GroupCommand, BatchCommand)
    ↓
CCRenderer (排序、批处理)
    ↓
OpenGL/OpenGL ES 渲染
```

### 2.1 RenderCommand - 渲染命令

```cpp
// 渲染命令类型
enum class Type {
    UNKNOWN_COMMAND,
    QUAD_COMMAND,       // 四边形命令（精灵、标签等）
    CUSTOM_COMMAND,     // 自定义命令（LayerColor、DrawNode等）
    GROUP_COMMAND,      // 分组命令（裁剪节点等）
    BATCH_COMMAND,      // 批量命令（SpriteBatchNode）
};

class RenderCommand {
public:
    Type getType() const;
    float getGlobalOrder() const;
};
```

## 8. 使用示例

### 8.1 纹理加载
```cpp
// 同步加载
auto texture = Director::getInstance()->getTextureCache()->addImage("hero.png");
auto sprite = Sprite::createWithTexture(texture);

// 异步加载
Director::getInstance()->getTextureCache()->addImageAsync("large_bg.png",
    [](Texture2D* texture) {
        auto sprite = Sprite::createWithTexture(texture);
        // 添加到场景...
    });
```

### 8.2 精灵帧
```cpp
// 加载plist图集
SpriteFrameCache::getInstance()->addSpriteFramesWithFile("sprites.plist");
auto frame = SpriteFrameCache::getInstance()->getSpriteFrameByName("hero_01.png");
auto sprite = Sprite::createWithSpriteFrame(frame);
```

### 8.3 自定义着色器
```cpp
auto program = new GLProgram();
program->initWithByteArrays(vertexShaderSource, fragmentShaderSource);
program->link();
program->updateUniforms();
sprite->setShaderProgram(program);
```
