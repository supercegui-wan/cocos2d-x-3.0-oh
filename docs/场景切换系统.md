# cocos2d-x 3.0-oh 场景切换系统 (Transition System)

## 概述

场景切换系统（Transition System）是 cocos2d-x 中用于在两个场景（Scene）之间执行动画过渡效果的子系统。它提供了从简单的淡入淡出到复杂的 3D 翻转、瓦片分割、翻页等 30 余种内置切换效果，并支持通过缓动接口（TransitionEaseScene）为切换动画叠加缓动曲线，以及通过继承扩展自定义切换效果。

**文件位置**:
- `cocos/2d/CCTransition.h` — 核心切换效果定义（TransitionScene 基类及 20+ 种切换效果）
- `cocos/2d/CCTransitionPageTurn.h` — 翻页切换效果（TransitionPageTurn）
- `cocos/2d/CCTransitionProgress.h` — 进度式切换效果（TransitionProgress 及 6 种子类）


### 1.2 核心机制

场景切换系统的核心思想是：**TransitionScene 本身是一个 Scene**，它接管 Director 的场景栈，在内部同时持有旧场景（`_outScene`）和新场景（`_inScene`），通过运行动画动作来驱动过渡效果，动画完成后调用 `finish()` 将新场景替换到 Director 中。

基本流程：

1. 创建 `TransitionScene` 子类实例，传入持续时间和目标场景
2. `Director::replaceScene(transition)` 将 TransitionScene 推入场景栈
3. `onEnter()` 被调用，子类在此设置初始状态并运行动画
4. 动画运行期间，`draw()` 负责渲染旧场景和新场景
5. 动画完成后，`finish()` 将新场景设置为 Director 的当前场景
6. `cleanup()` 清理旧场景资源

**场景层次控制**：通过 `_isInSceneOnTop` 标志和 `sceneOrder()` 虚函数控制新旧场景的渲染顺序（谁在上面）。

## 2. TransitionScene 基类

**文件**: `cocos/2d/CCTransition.h`

### 2.1 核心接口

```cpp
class TransitionScene : public Scene
{
public:
    // 方向枚举（供方向相关切换使用）
    enum class Orientation
    {
        LEFT_OVER = 0,   // 水平方向，左侧更近
        RIGHT_OVER = 1,  // 水平方向，右侧更近
        UP_OVER = 0,     // 垂直方向，上方更近
        DOWN_OVER = 1,   // 垂直方向，下方更近
    };

    // 创建切换（纯基类，不直接使用）
    static TransitionScene* create(float t, Scene* scene);

    // 切换完成后调用
    void finish();

    // 隐藏旧场景、显示新场景
    void hideOutShowIn();

    // 生命周期重写
    virtual void draw(Renderer* renderer, const kmMat4& transform, bool transformUpdated) override;
    virtual void onEnter() override;
    virtual void onExit() override;
    virtual void cleanup() override;

protected:
    // 初始化
    bool initWithDuration(float t, Scene* scene);

    // 控制场景渲染顺序（子类可重写）
    virtual void sceneOrder();

    // 定时回调，设置新场景到 Director
    void setNewScene(float dt);

    // 核心成员
    Scene* _inScene;              // 新场景（目标场景）
    Scene* _outScene;             // 旧场景（当前场景）
    float  _duration;             // 切换持续时间（秒）
    bool   _isInSceneOnTop;       // 新场景是否渲染在上层
    bool   _isSendCleanupToScene; // 是否发送清理消息给场景
};
```

### 2.2 生命周期详解

```
创建阶段:
  TransitionScene::create(t, scene)
    → initWithDuration(t, scene)
      → 保存 _duration
      → 保存 _inScene = scene
      → 保存 _outScene = Director::getInstance()->getRunningScene()
      → 设置 _isInSceneOnTop = false（默认旧场景在上）
      → 设置 _isSendCleanupToScene = false

onEnter() 阶段:
  → 子类重写，设置初始状态
  → 调用父类 Scene::onEnter()
  → sceneOrder() 确定新旧场景的渲染顺序
  → 创建并运行动画动作（Action）
  → 动画结束时调用 finish()

动画运行阶段:
  → draw() 渲染 _outScene 和 _inScene
  → 根据 _isInSceneOnTop 决定渲染顺序
  → 动画更新每帧驱动过渡效果

finish() 阶段:
  → 调用 setNewScene(0)，延迟一帧设置
  → setNewScene() 内部调用 Director::replaceScene(_inScene)
  → _outScene 的 cleanup 由 _isSendCleanupToScene 控制

onExit() 阶段:
  → 子类清理自身资源
  → 调用父类 Scene::onExit()

cleanup() 阶段:
  → 清理过渡场景自身资源
  → 若 _isSendCleanupToScene 为 true，清理 _outScene
```

### 2.3 场景管理

| 成员 | 说明 |
|------|------|
| `_inScene` | 目标场景（即将切换到的场景），在 `initWithDuration` 中由参数传入 |
| `_outScene` | 当前正在运行的场景，在 `initWithDuration` 中从 `Director::getRunningScene()` 获取 |
| `_isInSceneOnTop` | 控制渲染顺序：`true` 时新场景在上层，`false` 时旧场景在上层 |
| `_isSendCleanupToScene` | 控制 `finish()` 时是否清理旧场景，默认 `false` |

## 3. TransitionSceneOriented 方向基类

**文件**: `cocos/2d/CCTransition.h`

```cpp
class TransitionSceneOriented : public TransitionScene
{
public:
    static TransitionSceneOriented* create(float t, Scene* scene, Orientation orientation);

protected:
    Orientation _orientation;  // 方向

    bool initWithDuration(float t, Scene* scene, Orientation orientation);
};
```

TransitionSceneOriented 在 TransitionScene 基础上增加了 `_orientation` 成员，为需要方向参数的切换效果（如翻转类 FlipX、FlipY、FlipAngular 及其 Zoom 变体）提供统一的方向管理。

**create 重载说明**：翻转类子类同时提供两个 `create` 重载：
- `create(float t, Scene* s, Orientation o)` — 指定方向
- `create(float t, Scene* s)` — 使用默认方向

## 4. 切换效果分类详解

### 4.1 缩放类

#### TransitionRotoZoom — 旋转缩放切换

```cpp
auto transition = TransitionRotoZoom::create(1.0f, newScene);
```

效果：旧场景旋转并缩小淡出，然后新场景旋转并放大淡入。整体呈现一种"旋转门"式的过渡感。

#### TransitionJumpZoom — 跳跃缩放切换

```cpp
auto transition = TransitionJumpZoom::create(1.0f, newScene);
```

效果：旧场景缩小并跳跃飞出，然后新场景跳跃并放大飞入。相比 RotoZoom 增加了跳跃动画，动感更强。

#### TransitionShrinkGrow — 缩放切换（支持缓动）

```cpp
auto transition = TransitionShrinkGrow::create(1.0f, newScene);
```

效果：旧场景逐步缩小至消失，同时新场景逐步放大至正常大小。实现了 TransitionEaseScene 接口，可叠加缓动效果。

**继承关系**：`TransitionScene` + `TransitionEaseScene`

### 4.2 移入类（MoveIn）

移入类效果的特点是：**新场景从指定方向移入并覆盖在旧场景之上，旧场景保持不动**。

#### TransitionMoveInL — 从左侧移入

```cpp
auto transition = TransitionMoveInL::create(1.0f, newScene);
```

新场景从屏幕左侧移入，覆盖旧场景。

#### TransitionMoveInR — 从右侧移入

```cpp
auto transition = TransitionMoveInR::create(1.0f, newScene);
```

继承自 `TransitionMoveInL`，重写 `initScenes()` 设置新场景初始位置在屏幕右侧。

#### TransitionMoveInT — 从顶部移入

```cpp
auto transition = TransitionMoveInT::create(1.0f, newScene);
```

继承自 `TransitionMoveInL`，重写 `initScenes()` 设置新场景初始位置在屏幕顶部。

#### TransitionMoveInB — 从底部移入

```cpp
auto transition = TransitionMoveInB::create(1.0f, newScene);
```

继承自 `TransitionMoveInL`，重写 `initScenes()` 设置新场景初始位置在屏幕底部。

**继承关系**：`TransitionScene` + `TransitionEaseScene`（所有四个方向均支持缓动）

**关键方法**：
- `initScenes()` — 初始化新旧场景的初始位置
- `action()` — 返回移动动作（MoveTo）
- `easeActionWithAction()` — 包装缓动效果

### 4.3 滑入类（SlideIn）

滑入类效果的特点是：**新场景滑入的同时，旧场景也向相同方向滑出**。与 MoveIn 的区别在于 SlideIn 同时移动新旧两个场景。

#### TransitionSlideInL — 从左侧滑入

```cpp
auto transition = TransitionSlideInL::create(1.0f, newScene);
```

新场景从左侧滑入，旧场景向右滑出。

#### TransitionSlideInR — 从右侧滑入

```cpp
auto transition = TransitionSlideInR::create(1.0f, newScene);
```

新场景从右侧滑入，旧场景向左滑出。继承自 `TransitionSlideInL`，重写 `initScenes()`、`action()` 和 `sceneOrder()`。

#### TransitionSlideInT — 从顶部滑入

```cpp
auto transition = TransitionSlideInT::create(1.0f, newScene);
```

新场景从顶部滑入，旧场景向下滑出。

#### TransitionSlideInB — 从底部滑入

```cpp
auto transition = TransitionSlideInB::create(1.0f, newScene);
```

新场景从底部滑入，旧场景向上滑出。

**继承关系**：`TransitionScene` + `TransitionEaseScene`（所有四个方向均支持缓动）

**MoveIn 与 SlideIn 对比**：

| 特性 | MoveIn | SlideIn |
|------|--------|---------|
| 旧场景行为 | 保持不动 | 向相同方向滑出 |
| 新场景行为 | 从指定方向移入覆盖 | 从指定方向滑入 |
| 视觉效果 | 覆盖叠加 | 推动替换 |

### 4.4 翻转类

翻转类效果使用 3D 变换实现卡片翻转效果，前面是旧场景，后面是新场景。所有翻转类均继承自 `TransitionSceneOriented`。

#### TransitionFlipX — X轴翻转

```cpp
// 指定方向
auto transition = TransitionFlipX::create(1.0f, newScene, TransitionScene::Orientation::LEFT_OVER);
// 默认方向
auto transition = TransitionFlipX::create(1.0f, newScene);
```

沿 X 轴（水平轴）翻转，前面是旧场景，后面是新场景。

#### TransitionFlipY — Y轴翻转

```cpp
auto transition = TransitionFlipY::create(1.0f, newScene, TransitionScene::Orientation::UP_OVER);
```

沿 Y 轴（垂直轴）翻转。

#### TransitionFlipAngular — 角翻转

```cpp
auto transition = TransitionFlipAngular::create(1.0f, newScene, TransitionScene::Orientation::LEFT_OVER);
```

半水平半垂直翻转（即沿对角线方向翻转）。

#### TransitionZoomFlipX — 缩放X轴翻转

```cpp
auto transition = TransitionZoomFlipX::create(1.0f, newScene, TransitionScene::Orientation::LEFT_OVER);
```

在 X 轴翻转的同时带有缩放效果（缩小再放大）。

#### TransitionZoomFlipY — 缩放Y轴翻转

```cpp
auto transition = TransitionZoomFlipY::create(1.0f, newScene, TransitionScene::Orientation::UP_OVER);
```

在 Y 轴翻转的同时带有缩放效果。

#### TransitionZoomFlipAngular — 缩放角翻转

```cpp
auto transition = TransitionZoomFlipAngular::create(1.0f, newScene, TransitionScene::Orientation::LEFT_OVER);
```

在角翻转的同时带有缩放效果。

**注意**：翻转类效果标记了 `@js NA` 和 `@lua NA`，表示在 JavaScript 和 Lua 绑定中不可用（依赖 3D 投影矩阵）。

### 4.5 淡入淡出类

#### TransitionFade — 淡入淡出切换

```cpp
// 基本用法：淡入白色
auto transition = TransitionFade::create(1.0f, newScene);

// 指定淡入颜色
auto transition = TransitionFade::create(1.0f, newScene, Color3B(255, 0, 0)); // 红色
```

效果：旧场景先淡出到指定颜色，然后新场景从该颜色淡入。内部使用 `LayerColor` 覆盖层实现颜色过渡。

**成员**：`Color4B _color` — 淡入淡出中间颜色，默认黑色。

#### TransitionCrossFade — 交叉淡入淡出切换

```cpp
auto transition = TransitionCrossFade::create(1.0f, newScene);
```

效果：使用 `RenderTexture` 实现旧场景和新场景的直接交叉淡入淡出。旧场景逐渐变透明，同时新场景逐渐显现。

**与 Fade 的区别**：

| 特性 | TransitionFade | TransitionCrossFade |
|------|---------------|---------------------|
| 实现方式 | LayerColor 覆盖层 | RenderTexture 混合 |
| 中间状态 | 纯色过渡 | 两场景叠加 |
| 视觉效果 | 先全暗再全亮 | 渐变叠加 |

### 4.6 瓦片效果类

瓦片效果类使用 `NodeGrid` 将场景划分为网格瓦片，对每个瓦片应用独立的动画效果。

#### TransitionTurnOffTiles — 瓦片关闭切换

```cpp
auto transition = TransitionTurnOffTiles::create(1.0f, newScene);
```

效果：以随机顺序逐个"关闭"（翻转消失）旧场景的瓦片，露出新场景。

**继承关系**：`TransitionScene` + `TransitionEaseScene`

**成员**：`NodeGrid* _outSceneProxy` — 旧场景的网格代理节点

#### TransitionSplitCols — 列分割切换

```cpp
auto transition = TransitionSplitCols::create(1.0f, newScene);
```

效果：奇数列瓦片向上移动，偶数列瓦片向下移动，将旧场景分割后露出新场景。

**继承关系**：`TransitionScene` + `TransitionEaseScene`

**关键方法**：
- `action()` — 返回 3D 瓦片动作
- `switchTargetToInscene()` — 动画中途切换到新场景

#### TransitionSplitRows — 行分割切换

```cpp
auto transition = TransitionSplitRows::create(1.0f, newScene);
```

效果：奇数行瓦片向左移动，偶数行瓦片向右移动。继承自 `TransitionSplitCols`，重写 `action()` 方法。

**继承关系**：`TransitionSplitCols`（间接继承 `TransitionScene` + `TransitionEaseScene`）

#### TransitionFadeTR — 瓦片淡出（左上→右下）

```cpp
auto transition = TransitionFadeTR::create(1.0f, newScene);
```

效果：从左上角到右下角，按顺序淡出旧场景的瓦片。

**继承关系**：`TransitionScene` + `TransitionEaseScene`

**关键方法**：`actionWithSize(const Size& size)` — 根据场景尺寸生成瓦片淡出动作

#### TransitionFadeBL — 瓦片淡出（右下→左上）

```cpp
auto transition = TransitionFadeBL::create(1.0f, newScene);
```

效果：从右下角到左上角，按顺序淡出旧场景的瓦片。继承自 `TransitionFadeTR`，重写 `actionWithSize()`。

#### TransitionFadeUp — 瓦片淡出（下→上）

```cpp
auto transition = TransitionFadeUp::create(1.0f, newScene);
```

效果：从底部到顶部，逐行淡出旧场景的瓦片。继承自 `TransitionFadeTR`。

#### TransitionFadeDown — 瓦片淡出（上→下）

```cpp
auto transition = TransitionFadeDown::create(1.0f, newScene);
```

效果：从顶部到底部，逐行淡出旧场景的瓦片。继承自 `TransitionFadeTR`。

### 4.7 翻页类

#### TransitionPageTurn — 翻页切换

**文件**: `cocos/2d/CCTransitionPageTurn.h`

```cpp
// 正向翻页（从右下角向左上翻）
auto transition = TransitionPageTurn::create(1.0f, newScene, false);

// 反向翻页（从左侧翻向右侧）
auto transition = TransitionPageTurn::create(1.0f, newScene, true);
```

效果：模拟翻书页的效果，旧场景像书页一样从右下角被翻起，露出下面的新场景。`backwards` 参数为 `true` 时反转方向，新场景从左向右翻盖旧场景。

**重要提示**：TransitionPageTurn 使用 3D 动作，强烈建议在 Director 中开启深度缓冲：

```cpp
Director::getInstance()->setDepthBufferFormat(kDepthBuffer16);
```

**核心成员**：

| 成员 | 说明 |
|------|------|
| `_inSceneProxy` | 新场景的 NodeGrid 代理 |
| `_outSceneProxy` | 旧场景的 NodeGrid 代理 |
| `_back` | 是否反向翻页 |
| `POLYGON_OFFSET_FACTOR` / `POLYGON_OFFSET_UNITS` | 静态多边形偏移参数，防止 Z-fighting |

**关键方法**：
- `actionWithSize(const Size& size)` — 根据场景尺寸生成翻页 3D 动作
- `sceneOrder()` — 重写以控制前后页的渲染顺序
- `onEnablePolygonOffset()` / `onDisablePolygonOffset()` — 通过 CustomCommand 控制多边形偏移

### 4.8 进度类

**文件**: `cocos/2d/CCTransitionProgress.h`

进度类切换使用 `ProgressTimer` 和 `RenderTexture` 实现基于进度的场景揭示效果。所有进度类均继承自 `TransitionProgress`。

#### TransitionProgress 基类

```cpp
class TransitionProgress : public TransitionScene
{
protected:
    float _to;                    // 进度结束值
    float _from;                  // 进度起始值
    Scene* _sceneToBeModified;    // 被修改的场景

    // 子类重写以创建不同形状的 ProgressTimer
    virtual ProgressTimer* progressTimerNodeWithRenderTexture(RenderTexture* texture);
    virtual void setupTransition();  // 设置过渡
};
```

#### TransitionProgressRadialCCW — 逆时针径向

```cpp
auto transition = TransitionProgressRadialCCW::create(1.0f, newScene);
```

效果：以逆时针方向，从 12 点钟位置开始径向揭开新场景。

#### TransitionProgressRadialCW — 顺时针径向

```cpp
auto transition = TransitionProgressRadialCW::create(1.0f, newScene);
```

效果：以顺时针方向，从 12 点钟位置开始径向揭开新场景。

#### TransitionProgressHorizontal — 水平进度

```cpp
auto transition = TransitionProgressHorizontal::create(1.0f, newScene);
```

效果：水平方向（从左到右）以条形进度揭示新场景。

#### TransitionProgressVertical — 垂直进度

```cpp
auto transition = TransitionProgressVertical::create(1.0f, newScene);
```

效果：垂直方向（从下到上）以条形进度揭示新场景。

#### TransitionProgressInOut — 从内到外

```cpp

```

效果：从中心向四周扩展揭示新场景。重写了 `sceneOrder()` 和 `setupTransition()`。

#### TransitionProgressOutIn — 从外到内

```cpp
auto transition = TransitionProgressOutIn::create(1.0f, newScene);
```

效果：从四周向中心收缩揭示新场景。

## 5. TransitionEaseScene 缓动接口

**文件**: `cocos/2d/CCTransition.h`

```cpp
class TransitionEaseScene
{
public:
    virtual ~TransitionEaseScene() {}

    // 纯虚函数：将线性动作包装为缓动动作
    virtual ActionInterval* easeActionWithAction(ActionInterval* action) = 0;
};
```

TransitionEaseScene 是一个独立的抽象接口（非继承自 Ref），为 TransitionScene 子类提供缓动能力。实现了该接口的切换类可以在其 `easeActionWithAction()` 方法中返回包装后的动作，从而为切换动画叠加缓动效果。

**支持缓动的切换类**：

| 切换类 | 是否支持 TransitionEaseScene |
|--------|------------------------------|
| TransitionMoveInL/R/T/B | 是 |
| TransitionSlideInL/R/T/B | 是 |
| TransitionShrinkGrow | 是 |
| TransitionTurnOffTiles | 是 |
| TransitionSplitCols/Rows | 是 |
| TransitionFadeTR/BL/Up/Down | 是 |
| TransitionRotoZoom | 否 |
| TransitionJumpZoom | 否 |
| TransitionFade | 否 |
| TransitionCrossFade | 否 |
| TransitionFlipX/Y/Angular | 否 |
| TransitionZoomFlipX/Y/Angular | 否 |
| TransitionPageTurn | 否 |
| TransitionProgress 系列 | 否 |

**默认实现**：大多数支持缓动的切换类在 `easeActionWithAction()` 中返回 `EaseOut::create(action, 2.0f)`，即使用 2.0 速率的缓出效果。TransitionShrinkGrow 和 TransitionTurnOffTiles 返回 `EaseInOut::create(action, 2.0f)`。

## 7. 自定义切换效果

### 7.1 继承 TransitionScene 的步骤

创建自定义切换效果需继承 `TransitionScene` 并至少重写 `onEnter()` 方法：

```cpp
class MyCustomTransition : public TransitionScene
{
public:
    static MyCustomTransition* create(float t, Scene* scene)
    {
        auto ret = new (std::nothrow) MyCustomTransition();
        if (ret && ret->initWithDuration(t, scene))
        {
            ret->autorelease();
            return ret;
        }
        CC_SAFE_DELETE(ret);
        return nullptr;
    }

    virtual void onEnter() override
    {
        TransitionScene::onEnter();

        // 1. 设置初始状态
        //    例如：设置 _inScene 的初始位置、缩放、透明度等
        _inScene->setPosition(/* 初始位置 */);

        // 2. 创建动画动作
        auto action = /* 创建 ActionInterval */;

        // 3. 创建完成回调
        auto finishCallback = CallFunc::create(CC_CALLBACK_0(
            TransitionScene::finish, this));

        // 4. 运行动画序列
        auto seq = Sequence::create(action, finishCallback, nullptr);
        _inScene->runAction(seq);
    }

protected:
    MyCustomTransition() {}
    virtual ~MyCustomTransition() {}
};
```

### 7.2 支持缓动的自定义切换

如果希望自定义切换支持缓动，需要同时继承 `TransitionEaseScene`：

```cpp
class MyEasedTransition : public TransitionScene, public TransitionEaseScene
{
public:
    virtual ActionInterval* easeActionWithAction(ActionInterval* action) override
    {
        // 返回包装后的缓动动作
        return EaseInOut::create(action, 2.0f);
    }

    virtual void onEnter() override
    {
        TransitionScene::onEnter();

        auto moveAction = MoveTo::create(_duration, /* 目标位置 */);
        auto easedAction = easeActionWithAction(moveAction);
        auto finishCallback = CallFunc::create(CC_CALLBACK_0(
            TransitionScene::finish, this));
        auto seq = Sequence::create(easedAction, finishCallback, nullptr);
        _inScene->runAction(seq);
    }
};
```

### 7.3 需要重写的关键方法

| 方法 | 用途 | 是否必须重写 |
|------|------|-------------|
| `onEnter()` | 设置初始状态、运行动画 | 是 |
| `sceneOrder()` | 控制新旧场景渲染顺序 | 按需 |
| `onExit()` | 清理额外资源 | 按需 |
| `draw()` | 自定义渲染逻辑 | 按需 |

## 8. 注意事项与最佳实践

### 8.1 一般注意事项

1. **TransitionScene 生命周期**：TransitionScene 在 `finish()` 调用后会将控制权交还给 Director，因此不要在 `finish()` 之后再访问 TransitionScene 的成员。

2. **旧场景的清理**：默认情况下 `_isSendCleanupToScene` 为 `false`，旧场景不会被自动清理。如果旧场景不再需要，需确保在适当的时候清理。

3. **持续时间**：`_duration` 参数单位为秒。过短的持续时间可能导致动画不流畅，过长的持续时间会影响用户体验。建议范围：0.5 ~ 1.5 秒。

4. **场景内容复杂度**：切换效果的本质是对整个场景做动画，如果场景内容非常复杂（大量精灵、粒子等），部分 3D 或瓦片类切换效果可能出现性能问题。

### 8.2 翻转类注意事项

1. 翻转类（FlipX/Y/Angular 及其 Zoom 变体）基于 3D 投影矩阵实现，在 JavaScript 和 Lua 绑定中不可用（标记 `@js NA`、`@lua NA`）。

2. `Orientation` 枚举中 `LEFT_OVER` 与 `UP_OVER` 均为 0，`RIGHT_OVER` 与 `DOWN_OVER` 均为 1，具体含义取决于使用的翻转轴。

### 8.3 翻页类注意事项

1. **必须开启深度缓冲**：`TransitionPageTurn` 使用 3D 动作，需要深度缓冲来正确渲染前后页：

   ```cpp
   Director::getInstance()->setDepthBufferFormat(kDepthBuffer16);
   ```

2. 深度缓冲应在应用启动时设置一次，全局生效。

### 8.4 进度类注意事项

1. 进度类依赖 `RenderTexture` 和 `ProgressTimer`，在低端设备上可能产生额外性能开销。

2. `TransitionProgressInOut` 额外重写了 `sceneOrder()` 和 `setupTransition()`，其内部逻辑与其他进度类有所不同。

### 8.5 性能建议

| 场景 | 建议切换效果 |
|------|-------------|
| 简单场景切换 | TransitionFade、TransitionCrossFade、TransitionMoveInL |
| 需要视觉冲击力 | TransitionFlipX、TransitionRotoZoom、TransitionPageTurn |
| 低端设备 | TransitionFade、TransitionMoveInL（避免 3D 和瓦片效果） |
| 菜单/弹窗式切换 | TransitionSlideInL、TransitionMoveInB |
| 进度加载场景 | TransitionProgressRadialCCW、TransitionProgressHorizontal |

### 8.6 最佳实践

1. **避免连续快速切换**：在切换动画未完成时不要再次调用 `replaceScene()`，否则可能导致状态异常。

2. **使用 `Director::replaceScene()` 而非 `pushScene()`**：TransitionScene 设计用于替换场景，不适合与 `pushScene()`/`popScene()` 混用。

3. **不要在 `onEnter()` 中做耗时操作**：`onEnter()` 在切换动画开始前调用，耗时操作会导致动画延迟启动。

4. **预加载资源**：新场景的纹理、音频等资源应提前预加载，避免在切换过程中出现卡顿。
