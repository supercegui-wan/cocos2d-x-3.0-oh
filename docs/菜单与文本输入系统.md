# cocos2d-x 3.0-oh 菜单与文本输入系统 (Menu & TextField)

## 概述

菜单与文本输入系统是 cocos2d-x 3.0 中基于 `Node` 构建的传统 UI 交互体系，与 `cocos/ui/` 中的新版 UI 系统（`UIWidget` 体系）并列存在。菜单系统提供了完整的触摸驱动的菜单项层次结构，文本输入系统则通过 IME 委托机制处理平台原生输入。

**文件位置**：
- 菜单系统：`cocos/2d/CCMenu.h`、`cocos/2d/CCMenuItem.h`
- 文本输入：`cocos/2d/CCTextFieldTTF.h`、`cocos/2d/CCIMEDelegate.h`

### 菜单系统类层次结构

```
Node
├── Layer
│   └── Menu                          (菜单容器，管理触摸分发)
│
├── MenuItem                          (菜单项抽象基类)
│   ├── MenuItemLabel                 (标签菜单项，关联任意 Label 节点)
│   │   ├── MenuItemFont              (系统字体菜单项)
│   │   └── MenuItemAtlasFont         (图集字体菜单项)
│   ├── MenuItemSprite                (精灵菜单项，三态图片)
│   │   └── MenuItemImage             (图片菜单项，通过文件名创建精灵)
│   └── MenuItemToggle                (切换菜单项，包含多个子项)
│
└── Label                             (Label 基类)
    └── TextFieldTTF                  (文本输入框，同时实现 IMEDelegate)
```

### 文本输入系统类层次结构

```
IMEDelegate                            (IME 输入法委托接口)
  └── TextFieldTTF                    (TTF 文本输入框，继承 Label + IMEDelegate)

TextFieldDelegate                      (TextField 事件委托，带默认实现)
```

## 1. Menu 菜单容器

**文件**：`cocos/2d/CCMenu.h`

### 1.1 架构设计

`Menu` 继承自 `Layer`，作为多个 `MenuItem` 的容器，负责统一管理触摸事件并按命中测试结果将触摸分发到正确的菜单项。Menu 内部维护了一个状态机来跟踪当前触摸交互的完整生命周期。

```cpp
class Menu : public Layer {
public:
    enum class State {
        WAITING,          // 等待触摸
        TRACKING_TOUCH,   // 正在跟踪触摸（手指已按下但未抬起）
    };
};
```

**核心设计要点**：
- Menu 只接受 `MenuItem`（及其子类）作为子节点，`addChild` 被重写以确保类型安全
- 触摸事件通过 `onTouchBegan` → `onTouchMoved` → `onTouchEnded`/`onTouchCancelled` 完整链路处理
- 通过 `getItemForTouch()` 实现触摸坐标到菜单项的命中测试
- `Layer` 基类提供了触摸事件注册能力（`EventListenerTouchOneByOne`）

### 1.2 创建方式

| 创建方法 | 说明 |
|----------|------|
| `Menu::create()` | 创建一个空菜单，后续通过 `addChild` 添加菜单项 |
| `Menu::create(MenuItem* item, ...)` | 可变参数创建，以 `NULL`/`nullptr` 结尾 |
| `Menu::createWithArray(const Vector<MenuItem*>&)` | 通过 `Vector` 容器批量创建 |
| `Menu::createWithItem(MenuItem* item)` | 创建仅包含单个菜单项的菜单（主要用于脚本绑定） |
| `Menu::createWithItems(MenuItem* firstItem, va_list args)` | 通过 `va_list` 创建（内部使用） |

```cpp
// 示例1：空菜单 + 逐个添加
auto menu = Menu::create();
auto item1 = MenuItemFont::create("Start");
auto item2 = MenuItemFont::create("Quit");
menu->addChild(item1);
menu->addChild(item2);

// 示例2：可变参数创建（最常用）
auto menu = Menu::create(
    MenuItemFont::create("New Game",  CC_CALLBACK_1(HelloWorld::menuCallback, this)),
    MenuItemFont::create("Settings",  CC_CALLBACK_1(HelloWorld::menuCallback, this)),
    MenuItemFont::create("Quit",      CC_CALLBACK_1(HelloWorld::menuCallback, this)),
    nullptr  // 必须以 nullptr 结尾
);
```

### 1.3 对齐与布局

Menu 提供了一组布局方法，调用后会自动排列所有子菜单项的位置：

| 方法 | 说明 |
|------|------|
| `alignItemsVertically()` | 垂直对齐，子项在 Y 轴居中排列 |
| `alignItemsVerticallyWithPadding(float padding)` | 垂直对齐，指定间距 |
| `alignItemsHorizontally()` | 水平对齐，子项在 X 轴居中排列 |
| `alignItemsHorizontallyWithPadding(float padding)` | 水平对齐，指定间距 |
| `alignItemsInColumns(int columns, ...)` | 按列排列，可变参数指定每列行数，以 0 结尾 |
| `alignItemsInColumnsWithArray(const ValueVector& rows)` | 按列排列，通过 `ValueVector` 指定每列行数 |
| `alignItemsInRows(int rows, ...)` | 按行排列，可变参数指定每行列数，以 0 结尾 |
| `alignItemsInRowsWithArray(const ValueVector& columns)` | 按行排列，通过 `ValueVector` 指定每行列数 |

```cpp
// 示例：垂直对齐，间距 10 像素
menu->alignItemsVerticallyWithPadding(10.0f);

// 示例：按列排列，第1列2个，第2列3个（以0结尾）
menu->alignItemsInColumns(2, 3, 0);

// 示例：按行排列，第1行3个，第2行2个（以0结尾）
menu->alignItemsInRows(3, 2, 0);
```

### 1.4 触摸处理流程

```
┌─────────────────────────────────────────────────────────────┐
│  onTouchBegan(Touch*, Event*)                               │
│  1. 检查 _enabled 状态                                      │
│  2. 调用 getItemForTouch() 进行命中测试                      │
│  3. 找到命中项 → _selectedItem = item, item->selected()     │
│  4. 将 _state 设为 TRACKING_TOUCH                           │
│  5. 返回 true（吞下事件）                                    │
│                                                              │
│  onTouchMoved(Touch*, Event*)                               │
│  1. 如果 _state != TRACKING_TOUCH → 返回                    │
│  2. 命中测试：当前手指是否还在原选中项上？                    │
│     - 是 → item->selected()（保持选中状态）                  │
│     - 否 → item->unselected()（取消选中）                   │
│                                                              │
│  onTouchEnded(Touch*, Event*)                               │
│  1. 如果 _state != TRACKING_TOUCH → 返回                    │
│  2. 调用 _selectedItem->unselected()                        │
│  3. 调用 _selectedItem->activate()（触发回调）               │
│  4. 将 _state 重置为 WAITING                                │
│                                                              │
│  onTouchCancelled(Touch*, Event*)                           │
│  1. 如果 _state != TRACKING_TOUCH → 返回                    │
│  2. 调用 _selectedItem->unselected()（不触发回调）           │
│  3. 将 _state 重置为 WAITING                                │
└─────────────────────────────────────────────────────────────┘
```

### 1.5 关键属性与方法

| 成员 | 类型 | 说明 |
|------|------|------|
| `_enabled` | `bool` | 菜单是否启用，禁用时不响应触摸 |
| `_state` | `State` | 当前触摸状态（WAITING / TRACKING_TOUCH） |
| `_selectedItem` | `MenuItem*` | 当前触摸命中的菜单项（可能为 nullptr） |
| `setEnabled(bool)` | 方法 | 设置启用/禁用 |
| `isEnabled() const` | 方法 | 查询启用状态 |
| `getItemForTouch(Touch*)` | `protected` | 根据触摸坐标查找命中的菜单项 |

### 1.6 注意事项

- **子节点限制**：只有 `MenuItem` 及其子类才能被添加到 Menu 中，`addChild` 被重写以强制执行此约束
- **触摸穿透**：`onTouchBegan` 返回 `true` 后，该触摸事件不会继续向下传递
- **`removeChild` 重写**：移除子节点时，如果当前选中的正是被移除的节点，会将 `_selectedItem` 置为 `nullptr`
- **`onEnter`/`onExit`**：生命周期方法中注册/注销触摸事件监听器
- **`opacityModifyRGB`**：Menu 不支持此特性，`isOpacityModifyRGB()` 始终返回 `false`

## 2. MenuItem 菜单项体系

**文件**：`cocos/2d/CCMenuItem.h`

### 2.1 类层次结构

```
MenuItem                                   (抽象基类)
├── MenuItemLabel                          (关联 Label 节点)
│   ├── MenuItemFont                       (系统字体文本)
│   └── MenuItemAtlasFont                  (图集字体文本)
├── MenuItemSprite                         (精灵三态)
│   └── MenuItemImage                      (文件名创建精灵)
└── MenuItemToggle                         (切换容器)
```

### 2.2 MenuItem 基类

`MenuItem` 是所有菜单项的抽象基类，继承自 `Node`，定义了菜单项的基本行为：选中、取消选中、激活触发回调。

```cpp
class MenuItem : public Node {
public:
    static MenuItem* create();
    static MenuItem* create(const ccMenuCallback& callback);
    // 已废弃
    CC_DEPRECATED_ATTRIBUTE static MenuItem* create(Ref* rec, SEL_MenuHandler selector);

    virtual void activate();              // 激活（触发回调）
    virtual void selected();              // 被选中（手指按下或滑入）
    virtual void unselected();            // 取消选中（手指抬起或滑出）
    virtual bool isEnabled() const;       // 是否启用
    virtual void setEnabled(bool value);  // 设置启用/禁用
    virtual bool isSelected() const;      // 是否处于选中状态
    Rect rect() const;                    // 获取包围盒（用于命中测试）

    void setCallback(const ccMenuCallback& callback);
    CC_DEPRECATED_ATTRIBUTE void setTarget(Ref* rec, SEL_MenuHandler selector);
};
```

**核心属性**：

| 属性 | 类型 | 说明 |
|------|------|------|
| `_selected` | `bool` | 当前是否被选中（手指按下状态） |
| `_enabled` | `bool` | 是否启用，禁用时不可交互 |
| `_callback` | `ccMenuCallback` | 回调函数（`std::function<void(Ref*)>`） |
| `_target` | `Ref*` | （已废弃）旧式目标对象指针 |

**生命周期**：
```
selected()  →  unselected()  →  activate()
  按下/滑入      抬起/滑出        触发回调         → 回调执行
                                      ↑
                           仅当手指在菜单项上抬起时触发
```

### 2.3 回调机制

cocos2d-x 3.0 使用 `std::function` 作为回调类型，替代了旧式的 `target/selector` 模式：

```cpp
typedef std::function<void(Ref*)> ccMenuCallback;
```

**回调设置方式**：

```cpp
// 方式1：Lambda 表达式（推荐）
auto item = MenuItemFont::create("Start", [](Ref* sender) {
    CCLOG("Start button clicked!");
});

// 方式2：CC_CALLBACK 宏
auto item = MenuItemFont::create("Start",
    CC_CALLBACK_1(HelloWorld::menuCallback, this));

// 方式3：直接设置回调
item->setCallback([](Ref* sender) {
    // 处理点击
});

// 方式4：std::bind
item->setCallback(std::bind(&MyClass::onMenu, this, std::placeholders::_1));
```

## 3. MenuItemLabel 标签菜单项

**文件**：`cocos/2d/CCMenuItem.h`

### 3.1 概述

`MenuItemLabel` 继承自 `MenuItem`，可以关联任意实现了 `LabelProtocol` 的 `Node` 作为显示标签。支持的标签类型包括：`Label`、`LabelAtlas`、`BitmapFontAtlas`、`LabelTTF` 等。

### 3.2 核心接口

```cpp
class MenuItemLabel : public MenuItem {
public:
    static MenuItemLabel* create(Node* label);
    static MenuItemLabel* create(Node* label, const ccMenuCallback& callback);

    void setString(const std::string& label);      // 修改标签文本
    void setLabel(Node* node);                      // 替换标签节点
    Node* getLabel() const;                         // 获取标签节点
    void setDisabledColor(const Color3B& color);    // 设置禁用颜色
    const Color3B& getDisabledColor() const;        // 获取禁用颜色
};
```

**核心属性**：

| 属性 | 类型 | 说明 |
|------|------|------|
| `_label` | `Node*` | 关联的标签节点 |
| `_originalScale` | `float` | 原始缩放值（用于选中/取消缩放动画） |
| `_disabledColor` | `Color3B` | 禁用时的颜色（默认灰色） |
| `_colorBackup` | `Color3B` | 选中/禁用前的颜色备份 |

**状态行为**：
- `selected()`：将标签节点放大（`_originalScale * 1.2`），保存当前颜色
- `unselected()`：恢复原始缩放和颜色
- `setEnabled(false)`：将标签颜色设为 `_disabledColor`
- `setEnabled(true)`：恢复原始颜色

### 3.3 使用示例

```cpp
// 使用 Label 创建菜单项
auto label = Label::createWithTTF("Play", "fonts/arial.ttf", 24);
auto item = MenuItemLabel::create(label, [](Ref* sender) {
    CCLOG("Play clicked!");
});
item->setDisabledColor(Color3B::GRAY);

// 动态修改文本
item->setString("Pause");
```

## 4. MenuItemFont 字体菜单项

**文件**：`cocos/2d/CCMenuItem.h`

### 4.1 概述

`MenuItemFont` 继承自 `MenuItemLabel`，是使用系统 TTF 字体的菜单项。它默认使用 `Label::createWithSystemFont()` 创建内部标签。

### 4.2 接口

**静态（类级别）方法**：

| 方法 | 说明 |
|------|------|
| `static void setFontSize(int size)` | 设置全局默认字体大小 |
| `static int getFontSize()` | 获取全局默认字体大小 |
| `static void setFontName(const std::string& name)` | 设置全局默认字体名称 |
| `static const std::string& getFontName()` | 获取全局默认字体名称 |

**实例方法**：

| 方法 | 说明 |
|------|------|
| `void setFontSizeObj(int size)` | 设置当前实例字体大小 |
| `int getFontSizeObj() const` | 获取当前实例字体大小 |
| `void setFontNameObj(const std::string& name)` | 设置当前实例字体名称 |
| `const std::string& getFontNameObj() const` | 获取当前实例字体名称 |

> **注意**：C++ 不允许同名的静态和非静态成员函数共存，因此实例方法添加了 `Obj` 后缀。在 JS 绑定中这些方法映射为 `setFontSize`/`getFontSize`。

**创建方式**：

```cpp
static MenuItemFont* create(const std::string& value = "");
static MenuItemFont* create(const std::string& value, const ccMenuCallback& callback);
```

### 4.3 使用示例

```cpp
// 设置全局默认字体
MenuItemFont::setFontSize(32);
MenuItemFont::setFontName("Arial");

// 创建菜单项（使用全局默认字体设置）
auto item1 = MenuItemFont::create("Start", [](Ref* sender) {
    CCLOG("Start");
});

// 为单个实例覆盖字体大小
auto item2 = MenuItemFont::create("Options");
item2->setFontSizeObj(24);  // 仅此实例使用 24px
item2->setCallback([](Ref* sender) {
    CCLOG("Options");
});
```

## 5. MenuItemAtlasFont 图集字体菜单项

**文件**：`cocos/2d/CCMenuItem.h`

### 5.1 概述

`MenuItemAtlasFont` 继承自 `MenuItemLabel`，内部使用 `LabelAtlas` 作为标签。每个字符从指定的图集图片中按固定宽度取字模。

### 5.2 接口

```cpp
class MenuItemAtlasFont : public MenuItemLabel {
public:
    static MenuItemAtlasFont* create(
        const std::string& value,          // 显示的文本
        const std::string& charMapFile,    // 字符图集文件路径
        int itemWidth,                      // 每个字符宽度
        int itemHeight,                     // 每个字符高度
        char startCharMap                   // 起始字符
    );
    static MenuItemAtlasFont* create(
        const std::string& value,
        const std::string& charMapFile,
        int itemWidth, int itemHeight,
        char startCharMap,
        const ccMenuCallback& callback
    );
};
```

### 5.3 使用示例

```cpp
// 假设 "fonts/tuffy_bold_italic-charmap.png" 包含从 ' ' (空格) 开始的字符
auto item = MenuItemAtlasFont::create(
    "Play",
    "fonts/tuffy_bold_italic-charmap.png",
    48,   // 字符宽度
    64,   // 字符高度
    ' ',  // 起始字符
    [](Ref* sender) {
        CCLOG("Play clicked!");
    }
);
```

## 6. MenuItemSprite 精灵菜单项

**文件**：`cocos/2d/CCMenuItem.h`

### 6.1 概述

`MenuItemSprite` 继承自 `MenuItem`，支持三种状态的精灵图片：

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| **Normal**（正常） | 默认显示 | 手指未触摸时 |
| **Selected**（选中） | 手指按下或滑入 | `selected()` 被调用时 |
| **Disabled**（禁用） | 不可交互 | `setEnabled(false)` 时 |

三种状态的精灵通过 `updateImagesVisibility()` 在状态切换时自动管理可见性。

### 6.2 核心接口

```cpp
class MenuItemSprite : public MenuItem {
public:
    // 创建（无回调）
    static MenuItemSprite* create(
        Node* normalSprite,
        Node* selectedSprite,
        Node* disabledSprite = nullptr
    );
    // 创建（带回调）
    static MenuItemSprite* create(
        Node* normalSprite,
        Node* selectedSprite,
        Node* disabledSprite,
        const ccMenuCallback& callback
    );

    // 图片设置
    void setNormalImage(Node* image);
    Node* getNormalImage() const;
    void setSelectedImage(Node* image);
    Node* getSelectedImage() const;
    void setDisabledImage(Node* image);
    Node* getDisabledImage() const;
};
```

**核心属性**：

| 属性 | 类型 | 说明 |
|------|------|------|
| `_normalImage` | `Node*` | 正常状态显示节点 |
| `_selectedImage` | `Node*` | 选中状态显示节点 |
| `_disabledImage` | `Node*` | 禁用状态显示节点（可为 nullptr） |

**状态切换逻辑**：

```cpp
// selected() 被调用时：
//   显示 _selectedImage，隐藏 _normalImage 和 _disabledImage
// unselected() 被调用时：
//   显示 _normalImage，隐藏 _selectedImage 和 _disabledImage
// setEnabled(false) 时：
//   显示 _disabledImage（如果有），隐藏另外两个
// setEnabled(true) 时：
//   恢复显示 _normalImage
```

### 6.3 使用示例

```cpp
// 创建三种状态的精灵
auto normalSprite = Sprite::create("button_normal.png");
auto selectedSprite = Sprite::create("button_selected.png");
auto disabledSprite = Sprite::create("button_disabled.png");

auto item = MenuItemSprite::create(
    normalSprite,
    selectedSprite,
    disabledSprite,
    [](Ref* sender) {
        CCLOG("Button clicked!");
    }
);

// 运行时动态替换图片
item->setNormalImage(Sprite::create("new_normal.png"));
item->setSelectedImage(Sprite::create("new_selected.png"));
```

## 7. MenuItemImage 图片菜单项

**文件**：`cocos/2d/CCMenuItem.h`

### 7.1 概述

`MenuItemImage` 继承自 `MenuItemSprite`，通过图片文件名自动创建 `Sprite` 作为各状态显示。相比 `MenuItemSprite`，它简化了从文件路径创建菜单项的过程。

### 7.2 核心接口

```cpp
class MenuItemImage : public MenuItemSprite {
public:
    static MenuItemImage* create();
    static MenuItemImage* create(
        const std::string& normalImage,
        const std::string& selectedImage
    );
    static MenuItemImage* create(
        const std::string& normalImage,
        const std::string& selectedImage,
        const std::string& disabledImage
    );
    static MenuItemImage* create(
        const std::string& normalImage,
        const std::string& selectedImage,
        const std::string& disabledImage,
        const ccMenuCallback& callback
    );

    // 通过 SpriteFrame 设置
    void setNormalSpriteFrame(SpriteFrame* frame);
    void setSelectedSpriteFrame(SpriteFrame* frame);
    void setDisabledSpriteFrame(SpriteFrame* frame);
};
```

### 7.3 使用示例

```cpp
// 方式1：通过文件路径创建
auto item = MenuItemImage::create(
    "button_normal.png",
    "button_selected.png",
    "button_disabled.png",
    [](Ref* sender) {
        CCLOG("Image button clicked!");
    }
);

// 方式2：仅指定 normal 和 selected（disabled 根据 normal 自动调整）
auto simpleItem = MenuItemImage::create(
    "btn_ok.png",
    "btn_ok_pressed.png",
    [](Ref* sender) { CCLOG("OK"); }
);

// 方式3：通过 SpriteFrame 设置（使用精灵帧缓存中的帧）
auto frame = SpriteFrameCache::getInstance()->getSpriteFrameByName("btn_frame.png");
item->setNormalSpriteFrame(frame);
```

## 8. MenuItemToggle 切换菜单项

**文件**：`cocos/2d/CCMenuItem.h`

### 8.1 概述

`MenuItemToggle` 继承自 `MenuItem`，是一个包含多个子 `MenuItem` 的容器。每次点击时，它会在子项之间循环切换，每次只显示当前选中索引对应的子项。典型应用场景包括：开关按钮、音效开/关切换、语言切换等。

### 8.2 核心接口

```cpp
class MenuItemToggle : public MenuItem {
public:
    static MenuItemToggle* create();
    static MenuItemToggle* create(MenuItem* item);
    static MenuItemToggle* createWithCallback(
        const ccMenuCallback& callback,
        const Vector<MenuItem*>& menuItems
    );
    static MenuItemToggle* createWithCallback(
        const ccMenuCallback& callback,
        MenuItem* item, ...
    ) CC_REQUIRES_NULL_TERMINATION;

    void addSubItem(MenuItem* item);                 // 添加子项
    MenuItem* getSelectedItem();                      // 获取当前选中项
    unsigned int getSelectedIndex() const;            // 获取当前选中索引
    void setSelectedIndex(unsigned int index);        // 设置选中索引
    const Vector<MenuItem*>& getSubItems() const;     // 获取子项列表

};
```

**核心属性**：

| 属性 | 类型 | 说明 |
|------|------|------|
| `_selectedIndex` | `unsigned int` | 当前选中子项的索引 |
| `_subItems` | `Vector<MenuItem*>` | 所有子项列表 |

**切换逻辑**：
- `activate()`：`_selectedIndex` 循环递增（`(_selectedIndex + 1) % _subItems.size()`），更新显示并触发回调
- `selected()`、`unselected()`、`setEnabled()`：代理到当前选中子项

### 8.3 使用示例


## 9. TextFieldTTF 文本输入框

**文件**：`cocos/2d/CCTextFieldTTF.h`、`cocos/2d/CCIMEDelegate.h`

### 9.1 概述

`TextFieldTTF` 继承自 `Label` 并实现 `IMEDelegate` 接口，是 cocos2d-x 3.0 中基于 TTF 字体的文本输入框控件。它通过平台原生 IME（输入法编辑器）接收用户输入，支持占位符文本、安全输入（密码模式）和委托回调。

> **注意**：3.0 的 `cocos/ui/` 中还有一个 `UITextField`（基于 `UIWidget`），是新版 UI 系统的输入框。`TextFieldTTF` 是传统 2d 模块中的输入框。

### 9.2 创建方式

```cpp
class TextFieldTTF : public Label, public IMEDelegate {
public:
```

`TextFieldTTF` 实现了 `IMEDelegate` 的以下虚函数：

```cpp
protected:
```

## 10. TextFieldDelegate 委托接口

**文件**：`cocos/2d/CCTextFieldTTF.h`

### 10.1 概述

`TextFieldDelegate` 是一个委托接口类（所有方法均有默认实现，返回 `false`），允许开发者拦截 `TextFieldTTF` 的各类事件。所有回调方法返回 `bool` 值——返回 `true` 表示阻止默认行为，返回 `false` 表示允许默认行为继续。

### 10.2 接口定义

```cpp
class TextFieldDelegate {
public:
    virtual ~TextFieldDelegate() {}

    // IME 附加前回调。返回 true 阻止附加
    virtual bool onTextFieldAttachWithIME(TextFieldTTF* sender);

    // IME 分离前回调。返回 true 阻止分离
    virtual bool onTextFieldDetachWithIME(TextFieldTTF* sender);

    // 插入文本前回调。返回 true 阻止插入
    virtual bool onTextFieldInsertText(TextFieldTTF* sender, const char* text, size_t nLen);

    // 删除字符前回调。返回 true 阻止删除
    virtual bool onTextFieldDeleteBackward(TextFieldTTF* sender, const char* delText, size_t nLen);

    // 绘制前回调。返回 true 阻止绘制
    virtual bool onVisit(TextFieldTTF* sender, Renderer* renderer, const kmMat4& transform, bool transformUpdated);
};
```

### 10.3 使用示例

```cpp
class MyScene : public Scene, public TextFieldDelegate {
public:
    // 限制输入长度不超过 10 个字符
    virtual bool onTextFieldInsertText(TextFieldTTF* sender, const char* text, size_t nLen) override {
        if (sender->getCharCount() >= 10) {
            return true;  // 阻止插入
        }
        return false;     // 允许插入
    }

    // 只允许输入数字
    virtual bool onTextFieldInsertText(TextFieldTTF* sender, const char* text, size_t nLen) override {
        for (size_t i = 0; i < nLen; i++) {
            if (text[i] < '0' || text[i] > '9') {
                return true;  // 非数字，阻止插入
            }
        }
        return false;
    }

    // IME 附加时记录日志
    virtual bool onTextFieldAttachWithIME(TextFieldTTF* sender) override {
        CCLOG("TextField IME attached");
        return false;  // 允许附加
    }

    // IME 分离时记录日志
    virtual bool onTextFieldDetachWithIME(TextFieldTTF* sender) override {
        CCLOG("TextField IME detached, final text: %s", sender->getString().c_str());
        return false;
    }
};
```

## 11. 注意事项与最佳实践

### 11.1 Menu 相关

1. **触摸事件注册**：Menu 的 `onEnter()` / `onExit()` 中自动注册/注销触摸事件监听器，使用 `EventListenerTouchOneByOne` 模式。不要为 Menu 手动注册额外的触摸监听器。

2. **子节点类型限制**：只有 `MenuItem` 及其子类才能被添加到 Menu。`addChild` 的三个重载版本均被重写以执行类型检查。

3. **启用状态级联**：禁用 Menu（`setEnabled(false)`）会阻止所有子菜单项接收触摸事件，但不会自动禁用子项的 `_enabled` 属性。

4. **MenuItem 位置**：对齐方法（`alignItems*`）会修改所有子菜单项的 `setPosition`。如果手动设置了位置，调用对齐方法将覆盖手动设置。

5. **回调安全性**：`MenuItem` 的回调在 `activate()` 中执行。如果回调中删除了当前 Menu 或 MenuItem，请注意避免后续访问已释放的内存。

6. **MenuItemToggle 子项回调**：`MenuItemToggle` 的子项各自拥有独立的回调，但 `MenuItemToggle` 自身的回调会在切换时触发。子项的回调在 `activate()` 中不会被调用——只有 Toggle 自身的回调会触发。

### 11.2 TextFieldTTF 相关

1. **IME 生命周期**：移动平台上，`attachWithIME()` 会弹出系统键盘，`detachWithIME()` 会关闭键盘。在适当的时机调用（如点击输入框时 attach，点击其他区域时 detach）。

2. **多字节字符支持**：`TextFieldTTF` 内部维护 `_lens`（`LengthStack`）用于支持中文等多字节字符的删除操作。

3. **安全输入**：`setSecureTextEntry(true)` 后，显示的文本会被替换为掩码字符（通常是 `*`），但 `getString()` 返回的仍是真实文本。

4. **占位符**：当 `_inputText` 为空时，`visit()` 绘制 `_placeHolder` 文本；有输入内容时绘制 `_inputText`。

5. **委托返回值**：`TextFieldDelegate` 的所有回调返回 `true` 表示阻止默认行为。在 `onTextFieldInsertText` 中返回 `true` 可用于实现输入过滤（如限制长度、只允许数字等）。

6. **与 UITextField 的区别**：`TextFieldTTF` 位于 `cocos/2d/`，是传统模块；`UITextField` 位于 `cocos/ui/`，是新版 UI 系统。两者的 API 不同，不要混用。

### 11.3 通用最佳实践

1. **使用 Lambda 回调**：优先使用 `ccMenuCallback`（`std::function<void(Ref*)>`）配合 Lambda 表达式，避免旧式 `SEL_MenuHandler` + `Ref*` 模式的类型安全问题。

2. **资源管理**：`MenuItemSprite` 和 `MenuItemImage` 内部通过 `addChild` 持有图片节点，图片节点的生命周期由菜单项管理。外部不需要手动释放。

3. **菜单嵌套**：避免在 `MenuItem` 的回调中修改当前 Menu 的子节点结构（如 `addChild`/`removeChild`），这可能导致触摸状态机不一致。

4. **触摸优先级**：多个 Menu 共存时，`addChild` 的添加顺序决定触摸事件的处理优先级（后添加的在上层，先接收事件）。

5. **性能考虑**：`MenuItemToggle` 所有子项同时存在，只是通过可见性控制显示。如果子项数量很多（如超过 10 个），考虑使用其他方式实现切换。
