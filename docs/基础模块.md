# cocos2d-x 3.0-oh 基础模块 (base/)

## 1. CCRef - 引用计数基类

**文件**: `cocos/base/CCRef.h`

### 1.1 类层次结构
```
Clonable (接口)
  └── clone() = 0
Ref
  ├── retain() - 增加引用计数
  ├── release() - 减少引用计数，为0时销毁
  ├── autorelease() - 加入自动释放池
  └── getReferenceCount() - 获取当前引用计数
```

### 1.2 关键接口

| 方法 | 说明 |
|------|------|
| `void retain()` | 引用计数+1 |
| `void release()` | 引用计数-1，归零时delete |
| `Ref* autorelease()` | 将对象加入当前AutoreleasePool，返回this |
| `unsigned int getReferenceCount() const` | 获取当前引用计数 |

### 1.3 回调选择器类型定义
```cpp
typedef void (Ref::*SEL_CallFunc)();
typedef void (Ref::*SEL_CallFuncN)(Node*);
typedef void (Ref::*SEL_CallFuncND)(Node*, void*);
typedef void (Ref::*SEL_CallFuncO)(Ref*);
typedef void (Ref::*SEL_MenuHandler)(Ref*);
typedef void (Ref::*SEL_SCHEDULE)(float);

// 使用宏
#define callfunc_selector(_SELECTOR) static_cast<cocos2d::SEL_CallFunc>(&_SELECTOR)
#define callfuncN_selector(_SELECTOR) static_cast<cocos2d::SEL_CallFuncN>(&_SELECTOR)
#define callfuncND_selector(_SELECTOR) static_cast<cocos2d::SEL_CallFuncND>(&_SELECTOR)
#define callfuncO_selector(_SELECTOR) static_cast<cocos2d::SEL_CallFuncO>(&_SELECTOR)
#define menu_selector(_SELECTOR) static_cast<cocos2d::SEL_MenuHandler>(&_SELECTOR)
#define schedule_selector(_SELECTOR) static_cast<cocos2d::SEL_SCHEDULE>(&_SELECTOR)
```

### 1.4 使用示例
```cpp
auto sprite = new Sprite();  // 引用计数=1
sprite->retain();            // 引用计数=2
sprite->release();           // 引用计数=1
sprite->autorelease();       // 加入自动释放池，池排空时release
```

## 2. AutoreleasePool - 自动释放池

**文件**: `cocos/base/CCAutoreleasePool.h`

### 2.1 关键接口
- `void addObject(Ref* object)` - 添加对象
- `void clear()` - 清空池（对所有对象调用release）
- `bool isClearing() const` - 是否正在清空（仅DEBUG模式）
- `bool contains(Ref* object) const` - 检查池中是否包含指定对象
- `void dump()` - 调试输出池中对象
- 每个主循环帧自动创建和排空

### 2.2 PoolManager - 池管理器
- `static PoolManager* getInstance()` - 获取单例
- `static void destroyInstance()` - 销毁单例
- `AutoreleasePool* getCurrentPool() const` - 获取当前激活的池
- `bool isObjectInPools(Ref* obj) const` - 检查对象是否在任意池中

### 3.1 支持的类型 (Type枚举)
| 类型 | 说明 |
|------|------|
| NONE | 空值 |
| BYTE | unsigned char |
| INTEGER | int |
| FLOAT | float |
| DOUBLE | double |
| BOOLEAN | bool |
| STRING | std::string |
| VECTOR | ValueVector |

### 3.2 类型别名
```cpp
typedef std::vector<Value> ValueVector;
typedef std::unordered_map<std::string, Value> ValueMap;
typedef std::unordered_map<int, Value> ValueMapIntKey;
```

### 3.3 关键接口
- 构造函数支持所有基本类型和容器类型
- 移动构造函数 `Value(Value&& other)` 和移动赋值 `operator=(Value&& other)`
- `static const Value Null` - 空值常量
- `asByte()/asInt()/asFloat()/asDouble()/asBool()/asString()` - 类型转换
- `asValueVector()` / `const asValueVector() const` - 容器访问（读写/只读）
- `asValueMap()` / `const asValueMap() const` - 容器访问（读写/只读）
- `asIntKeyMap()` / `const asIntKeyMap() const` - 容器访问（读写/只读）
- `getType()` - 获取当前类型
- `isNull()` - 判断是否为空
- `getDescription()` - 获取描述字符串
- 运算符重载: `operator=`, `operator=` (移动)

### 3.4 使用示例
```cpp
Value v1(100);
Value v2("hello");
Value v3(3.14f);

ValueVector vec;
vec.push_back(Value(1));
vec.push_back(Value("test"));

Value v4(vec);
int val = v1.asInt();  // 100
```

## 5. CCVector - 引用计数安全容器

**文件**: `cocos/base/CCVector.h`

### 5.1 关键特性
- 模板参数必须是 Ref* 的子类 (static_assert)
- 自动管理引用计数（pushBack/insert时retain，erase/popBack/clear时release）
- 基于 std::vector 实现

### 5.2 关键接口
```cpp
template<class T>
class Vector {
    // 容量
    ssize_t size() const;
    ssize_t capacity() const;
    bool empty() const;
    ssize_t max_size() const;
    void reserve(ssize_t n);
    void shrinkToFit();           // 收缩内存
    
    // 访问
    T at(ssize_t index) const;
    T front() const;
    T back() const;
    T getRandomObject() const;
    
    // 添加
    void pushBack(T object);       // 自动retain
    void pushBack(const Vector<T>& other);
    void insert(ssize_t index, T object);
    
    // 移除
    void popBack();                // 自动release
    void eraseObject(T object, bool removeAll=false);
    iterator erase(iterator position);          // 按迭代器删除
    iterator erase(iterator first, iterator last); // 按范围删除
    iterator erase(ssize_t index);              // 按索引删除
    void clear();                  // 全部release
    
    // 查找
    ssize_t getIndex(T object) const;
    const_iterator find(T object) const;  // const版本查找
    iterator find(T object);
    bool contains(T object) const;
    
    // 操作
    void swap(T o1, T o2);              // 按对象交换
    void swap(ssize_t index1, ssize_t index2); // 按索引交换
    void replace(ssize_t index, T object);
    void reverse();
    bool equals(const Vector<T>& other); // 比较相等
    
    // 迭代器
    iterator begin()/end();
    const_iterator begin()/end() const;
    const_iterator cbegin()/cend() const;
    reverse_iterator rbegin()/rend();
    const_reverse_iterator crbegin()/crend() const;
    
    // 支持移动构造/赋值
    Vector(Vector&& other);
    Vector& operator=(Vector&& other);
};
```

## 6. CCMap - 引用计数安全字典

**文件**: `cocos/base/CCMap.h`

### 6.1 关键特性
- 基于 std::unordered_map 实现
- 自动管理引用计数
- 模板参数 V 必须是 Ref* 的子类

### 6.2 关键接口
```cpp
template<class K, class V>
class Map {
    ssize_t size() const;
    bool empty() const;
    void reserve(ssize_t capacity);  // 预留容量
    
    // 桶信息（unordered_map）
    ssize_t bucketCount() const;     // 桶数量
    ssize_t bucketSize(ssize_t n) const; // 第n个桶的元素数
    ssize_t bucket(const K& k) const;    // 键k所在的桶号
    
    const V at(const K& key) const;  // const版本访问
    V at(const K& key);              // 不存在返回nullptr
    void insert(const K& key, V object); // 自动retain
    size_t erase(const K& key);      // 自动release
    void erase(const std::vector<K>& keys); // 按key列表删除
    iterator erase(const_iterator position); // 按迭代器删除
    void clear();                    // 全部release
    
    std::vector<K> keys() const;
    std::vector<K> keys(V object) const;
    V getRandomObject() const;
    
    const_iterator find(const K& key) const; // const版本
    iterator find(const K& key);
    
    // 迭代器
    iterator begin()/end();
    const_iterator begin()/end() const;
    const_iterator cbegin()/cend() const;
    
    // 支持移动构造/赋值
    Map(Map&& other);
    Map& operator=(Map&& other);
};
```

## 7. CCPlatformMacros - 平台宏定义

**文件**: `cocos/base/CCPlatformMacros.h`

### 7.1 命名空间宏
```cpp
#define NS_CC_BEGIN    namespace cocos2d {

#define USING_NS_CC    using namespace cocos2d
```

### 7.2 属性声明宏
- `CC_PROPERTY_READONLY(type, name, func)` - 只读属性
- `CC_PROPERTY(type, name, func)` - 读写属性
- `CC_SYNTHESIZE_READONLY(type, name, func)` - 自动合成只读属性
- `CC_SYNTHESIZE(type, name, func)` - 自动合成读写属性
- `CC_SYNTHESIZE_RETAIN(type, name, func)` - 带引用计数的合成属性

### 7.3 创建工厂宏
```cpp
#define CREATE_FUNC(__TYPE__) \
static __TYPE__* create() { \
    __TYPE__ *pRet = new __TYPE__(); \
    if (pRet && pRet->init()) { \
        pRet->autorelease(); \
        return pRet; \
    } else { \
        delete pRet; \
        return nullptr; \
    } \
}
```

### 7.4 内存安全宏
- `CC_SAFE_DELETE(p)` - 安全delete并置nullptr
- `CC_SAFE_RELEASE(p)` - 安全release
- `CC_SAFE_RELEASE_NULL(p)` - 安全release并置nullptr
- `CC_SAFE_RETAIN(p)` - 安全retain

### 7.5 调试日志宏
- `CCLOG(format, ...)` - 调试日志（COCOS2D_DEBUG=1时激活）
- `CCLOGERROR(format, ...)` - 错误日志
- `CCLOGWARN(format, ...)` - 警告日志（含函数名）
- `CCLOGINFO(format, ...)` - 信息日志（COCOS2D_DEBUG>1时激活）
