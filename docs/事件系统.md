# cocos2d-x 3.0-oh 事件系统 (Event System)

## 1. 概述

cocos2d-x 3.0 引入了全新的事件分发系统，替代旧的 TouchDispatcher。核心组件：

- **Event**: 事件数据
- **EventListener**: 事件监听器
- **EventDispatcher**: 事件分发器

**文件位置**: `cocos/2d/CCEvent.h`, `CCEventType.h`, `CCEventListener.h`, `CCEventDispatcher.h`

## 2. 事件类型 (EventType)

`Event::Type` 枚举定义在 `CCEvent.h` 中的 `Event` 类内部（见第3节）。`CCEventType.h` 仅包含两个用于 `NotificationCenter` 的宏：

```cpp
#define EVENT_COME_TO_FOREGROUND    "event_come_to_foreground"
#define EVENT_COME_TO_BACKGROUND    "event_come_to_background"
```

## 3. Event - 事件基类

**文件**: `cocos/2d/CCEvent.h`

```cpp
class Event : public Ref {
public:
    enum class Type { TOUCH, KEYBOARD, ACCELERATION, MOUSE, CUSTOM };
    
    Type getType() const;
    void stopPropagation();            // 停止事件传播
    bool isStopped() const;            // 是否被停止
    Node* getCurrentTarget();          // 当前目标节点
    
protected:
    Type _type;
    bool _isStopped;
    Node* _currentTarget;
};
```

## 4. EventListener - 事件监听器

**文件**: `cocos/2d/CCEventListener.h`

### 4.1 基类

```cpp
class EventListener : public Ref {
public:
    enum class Type { UNKNOWN, TOUCH_ONE_BY_ONE, TOUCH_ALL_AT_ONCE,
                      KEYBOARD, MOUSE, ACCELERATION, CUSTOM };
    
    virtual bool checkAvailable() = 0;
    virtual EventListener* clone() = 0;
    
    // 属性
    void setEnabled(bool enabled);
    bool isEnabled() const;
    
protected:
    // 回调注册
    std::function<void(Event*)> _onEvent;  // 通用事件回调
    
    Type _type;
    Node* _node;                  // 绑定的节点
    bool _isEnabled;
    bool _isRegistered;
    int _fixedPriority;           // 固定优先级
    std::string _listenerID;      // 监听器标识
};
```

## 5. EventDispatcher - 事件分发器

**文件**: `cocos/2d/CCEventDispatcher.h`

```cpp
class EventDispatcher : public Ref {
public:
    // 添加监听器
    void addEventListenerWithSceneGraphPriority(EventListener* listener, Node* node);
    void addEventListenerWithFixedPriority(EventListener* listener, int fixedPriority);
    EventListenerCustom* addCustomEventListener(const std::string& eventName,
                                const std::function<void(EventCustom*)>& callback);
    
    // 移除监听器
    void removeEventListener(EventListener* listener);
    void removeEventListenersForType(EventListener::Type listenerType);
    void removeEventListenersForTarget(Node* target, bool recursive = false);
    void removeCustomEventListeners(const std::string& customEventName);
    void removeAllEventListeners();
    
    // 控制
    void pauseEventListenersForTarget(Node* target, bool recursive = false);
    void resumeEventListenersForTarget(Node* target, bool recursive = false);
    void setPriority(EventListener* listener, int fixedPriority);
    void setEnabled(bool isEnabled);
    bool isEnabled() const;
    
    // 分发
    void dispatchEvent(Event* event);
    void dispatchCustomEvent(const std::string& eventName, void* optionalUserData = nullptr);
};
```

## 6. 使用示例

### 6.1 触摸事件

```cpp
// 方式1：直接创建监听器
auto listener = EventListenerTouchOneByOne::create();
listener->setSwallowTouches(true);
listener->onTouchBegan = [](Touch* touch, Event* event) {
    // 返回true表示继续接收后续事件
    return true;
};
listener->onTouchMoved = [](Touch* touch, Event* event) {
    // 处理移动
};
listener->onTouchEnded = [](Touch* touch, Event* event) {
    // 处理结束
};
_eventDispatcher->addEventListenerWithSceneGraphPriority(listener, this);

// 方式2：通过Layer重写
class MyLayer : public Layer {
    virtual bool onTouchBegan(Touch* touch, Event* event) override { return true; }
    virtual void onTouchMoved(Touch* touch, Event* event) override {}
    virtual void onTouchEnded(Touch* touch, Event* event) override {}
};
```

### 6.2 键盘事件

```cpp
auto listener = EventListenerKeyboard::create();
listener->onKeyPressed = [](EventKeyboard::KeyCode keyCode, Event* event) {
    if (keyCode == EventKeyboard::KeyCode::KEY_ESCAPE) {
        Director::getInstance()->end();
    }
};
listener->onKeyReleased = [](EventKeyboard::KeyCode keyCode, Event* event) {
    CCLOG("Key released: %d", (int)keyCode);
};
_eventDispatcher->addEventListenerWithSceneGraphPriority(listener, this);
```

### 6.3 自定义事件

```cpp
// 注册
auto listener = EventListenerCustom::create("my_event", [](EventCustom* event) {
    auto data = static_cast<MyData*>(event->getUserData());
    // 处理数据
});
_eventDispatcher->addEventListenerWithFixedPriority(listener, 1);

// 分发
_eventDispatcher->dispatchCustomEvent("my_event", &myData);
```

### 6.4 优先级说明

- **SceneGraphPriority**: 基于场景图的优先级，与节点Z序相关
- **FixedPriority**: 固定数字优先级，数字越小优先级越高（越先响应）
