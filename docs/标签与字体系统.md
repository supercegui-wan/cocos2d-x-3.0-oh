> **版本**：1.0.0
>
> **更新日期**：2026-07-28
>
> **适用范围**：cocos2d-x 3.0-oh（OpenHarmony 适配版）
>
> **本文档定位**：cocos2d-x 3.0-oh 标签与字体系统的企业级技术文档，覆盖 Label 统一标签系统、Font 字体体系、FontAtlas 字体图集、FontAtlasCache 缓存、旧版兼容标签及迁移指南。

---

## 1. 概述

cocos2d-x 3.0 引入了全新的统一标签系统 `Label`，替代了 2.x 版本中分散的 `LabelTTF`、`LabelBMFont` 和 `LabelAtlas`。新系统基于 `Font` 抽象字体体系与 `FontAtlas` 字体图集机制，将多种字体类型统一到同一套架构下，支持 TTF（TrueType / 系统字体）、BMFont（位图字体）、CharMap（字符映射字体）和 StringTexture（字符串纹理）四种标签类型，并提供阴影、描边、发光等文本特效，以及距离场字体（DistanceField）支持。

**文件位置**：`cocos/2d/CCLabel.h`、`cocos/2d/CCFont.h`、`cocos/2d/CCFontAtlas.h`、`cocos/2d/CCFontAtlasCache.h`

## 2. Label（统一标签系统）

### 2.1 架构设计

`Label` 是 cocos2d-x 3.0 标签系统的核心类，继承自 `SpriteBatchNode` 并实现 `LabelProtocol` 接口。它通过组合 `Font` 和 `FontAtlas` 来完成字形获取、纹理管理和渲染，统一了原来分散的三种标签实现。

```text
SpriteBatchNode          LabelProtocol
       \                    /
        \                  /
         \                /
              Label
               |
    ┌──────────┼──────────┐
    |          |          |
  Font      FontAtlas   LetterInfo[]
 (字体)    (字体图集)    (字形信息)
```

**核心设计要点**：

- **Label 继承自 SpriteBatchNode**：每个字符以 `Sprite` 的形式存在，作为 `SpriteBatchNode` 的子节点实现批量渲染，减少 DrawCall。
- **Label 实现 LabelProtocol**：提供 `setString()` / `getString()` 统一接口。
- **Font 负责字形数据**：通过多态子类（`FontFreeType`、`FontFNT`、`FontCharMap`）提供不同字体类型的字形位图、字距等信息。
- **FontAtlas 负责纹理管理**：将字形位图打包到一张或多张纹理图集中，维护字形定义（`FontLetterDefinition`）的查找表。
- **LetterInfo 记录布局信息**：每个字符在纹理中的位置、在屏幕上的显示位置和所属的纹理页索引。

### 2.2 标签类型枚举

```cpp
// LabelType 是 Label 类的 protected 内部枚举，非独立公开枚举
enum class LabelType {
    TTF,            // TrueType / 系统字体
    BMFONT,         // 位图字体（.fnt + .png）
    CHARMAP,        // 字符映射字体（固定宽度的字符图集）
    STRING_TEXTURE  // 字符串纹理（兼容模式，内部将完整字符串渲染为一张纹理）
};
```

### 2.3 GlyphCollection 字形集合

```cpp
enum class GlyphCollection {
    DYNAMIC,    // 动态字形集合：按需逐步加载字形到纹理图集
    NEHE,       // NEHE 预定义字形（94个常用 ASCII 字符）
    ASCII,      // 完整 ASCII 字符集（256个字符）
    CUSTOM      // 自定义字形集合：由用户指定需要加载的字符集
};
```

| 集合类型 | 字符数量 | 说明 |
|----------|----------|------|
| `DYNAMIC` | 按需 | 默认选项，运行时动态加载。首次渲染字符时实时生成字形，适合中文等多字节字符集 |
| `NEHE` | 94 | 包含 `!` 到 `~` 的 94 个打印 ASCII 字符（空格 + 大小写字母 + 数字 + 标点），适合英文界面 |
| `ASCII` | 256 | 完整 ASCII 字符集（0x00-0xFF），适合需要扩展 ASCII 的场景 |
| `CUSTOM` | 自定义 | 通过 `customGlyphs` 参数指定需要预加载的字符集，适合固定文本内容的场景 |

### 2.4 TTFConfig 配置结构

```cpp
typedef struct _ttfConfig {
    std::string fontFilePath;   // 字体文件路径（.ttf/.otf 文件路径，或留空使用系统字体）
    int fontSize;               // 字体大小（像素）
    GlyphCollection glyphs;     // 字形集合策略
    const char *customGlyphs;   // 自定义字形集合字符串（当 glyphs == CUSTOM 时生效）
    bool distanceFieldEnabled;  // 是否启用距离场字体
    int outlineSize;            // 描边宽度（>0 时自动禁用 distanceFieldEnabled）

    _ttfConfig(const char* filePath = "", int size = 12,
               const GlyphCollection& glyphCollection = GlyphCollection::DYNAMIC,
               const char *customGlyphCollection = nullptr,
               bool useDistanceField = false, int outline = 0);
} TTFConfig;
```

**注意**：构造时若 `outline > 0`，会将 `distanceFieldEnabled` 强制设为 `false`，因为描边和距离场互斥。

### 2.8 特效系统

Label 支持三种文本特效，它们在渲染时通过额外的绘制 Pass 实现：

#### 2.8.1 阴影（Shadow）

```cpp
virtual void enableShadow(
    const Color4B& shadowColor = Color4B::BLACK,  // 阴影颜色（默认黑色）
    const Size& offset = Size(2, -2),             // 阴影偏移（默认右下）
    int blurRadius = 0                             // 模糊半径（暂未实现）
);
```

阴影效果通过 `_shadowNode`（一个 `Sprite` 实例）实现，在文本下方以偏移位置绘制一份带颜色的副本。所有标签类型均支持阴影。

#### 2.8.2 描边（Outline）

```cpp
// 仅支持 TTF 字体
virtual void enableOutline(
    const Color4B& outlineColor,  // 描边颜色
    int outlineSize = -1          // 描边宽度（-1 使用 TTFConfig 中的 outlineSize）
);
```

描边效果通过 FreeType 的 `FT_Stroker` 在字形生成时预计算描边位图，然后在纹理中同时存储填充和描边信息。**仅 TTF 类型标签支持**。

描边与距离场字体互斥：当 `TTFConfig.outlineSize > 0` 时，`distanceFieldEnabled` 会被自动设为 `false`。

#### 2.8.3 发光（Glow）

```cpp
// 仅支持 TTF 字体
virtual void enableGlow(const Color4B& glowColor);
```

发光效果在描边基础上叠加一层颜色，产生类似霓虹灯的视觉效果。**仅 TTF 类型标签支持**。

#### 2.8.4 禁用特效

```cpp
// 禁用所有特效（阴影/描边/发光），恢复 NORMAL 渲染
virtual void disableEffect();
```

#### 2.8.5 特效与渲染流程

Label 的 `visit()` 方法会根据当前特效类型决定渲染顺序：

1. **NORMAL**：直接绘制文本
2. **OUTLINE / GLOW**：通过自定义着色器（`_customCommand`）绘制，使用 `_uniformEffectColor` 和 `_uniformTextColor` 传递特效颜色和文本颜色
3. **SHADOW**：
   - 先绘制 `_shadowNode`（阴影层），使用 `_shadowTransform` 变换矩阵偏移
   - 再绘制主文本层

### 2.9 距离场字体（DistanceField）

距离场字体是一种基于有符号距离场（Signed Distance Field, SDF）的字体渲染技术。在 `TTFConfig` 中设置 `distanceFieldEnabled = true` 即可启用。

**原理**：在预生成阶段，为每个字形计算距离场纹理（存储每个像素到字形边缘的最短距离），运行时通过着色器根据距离值重建清晰的字形边缘。

**优势**：
- 缩放时不会出现锯齿，任意大小都能保持清晰
- 可以在着色器中实现描边、发光、投影等特效，无需额外纹理
- 减少纹理图集大小（一个字形可以覆盖多种字号）

**使用条件**：
- `FontFreeType` 在创建字形时，通过 `DistanceMapSpread` 常量控制距离场扩展范围
- 需要对应的 SDF 着色器程序支持
- `Label` 内部通过 `_useDistanceField` 标志位与 `_useA8Shader` 标志位控制渲染路径

**静态常量**：
```cpp
static const int Label::DistanceFieldFontSize;  // 距离场字体生成时的基准字号
```

### 2.10 内部实现

#### 2.10.1 LetterInfo 结构体

```cpp
struct LetterInfo {
    FontLetterDefinition def;  // 字形定义（纹理坐标、尺寸等）
    Point position;            // 屏幕上的显示位置
    Size  contentSize;         // 内容尺寸
    int   atlasIndex;          // 纹理页索引
};
```

每个字符对应一个 `LetterInfo`，存储在 `_lettersInfo` 向量中，按字符串顺序排列。

#### 2.10.2 关键成员变量

| 成员 | 类型 | 说明 |
|------|------|------|
| `_batchNodes` | `vector<SpriteBatchNode*>` | 批量渲染节点（每个纹理页一个） |
| `_fontAtlas` | `FontAtlas*` | 字体图集 |
| `_lettersInfo` | `vector<LetterInfo>` | 字形信息数组 |
| `_currentLabelType` | `LabelType` | 当前标签类型 |
| `_originalUTF8String` | `string` | 原始 UTF-8 字符串 |
| `_currentUTF16String` | `unsigned short*` | 当前 UTF-16 字符串（用于渲染） |
| `_originalUTF16String` | `unsigned short*` | 原始 UTF-16 字符串 |
| `_horizontalKernings` | `int*` | 水平字距数组 |
| `_commonLineHeight` | `float` | 公共行高 |
| `_lineBreakWithoutSpaces` | `bool` | 是否允许单词内断行 |
| `_currLabelEffect` | `LabelEffect` | 当前特效类型 |
| `_shadowNode` | `Sprite*` | 阴影节点 |
| `_textSprite` | `Sprite*` | 兼容模式下的文本精灵（用于 `STRING_TEXTURE` 类型） |
| `_compatibleMode` | `bool` | 兼容模式标志 |
| `_useDistanceField` | `bool` | 是否使用距离场字体 |
| `_useA8Shader` | `bool` | 是否使用 A8 着色器（单通道 Alpha 纹理） |
| `_currNumLines` | `int` | 当前行数 |
| `_fontScale` | `float` | 字体缩放比例 |

#### 2.10.3 渲染流程

1. **`setString()`**：设置文本 → 标记 `_contentDirty = true`
2. **`updateContent()`**：检查内容脏标记 → 更新字体配置 → 构建字形信息 → 计算布局和对齐
3. **`visit()`**：根据特效类型决定绘制顺序 → 调用 `draw()` 或 `drawTextSprite()`
4. **`draw()`**：遍历 `_batchNodes`，每个 `SpriteBatchNode` 对应一个纹理页，批量提交绘制命令
5. **`onDraw()`**：处理自定义着色器命令（用于描边/发光效果）

#### 2.10.4 字符串处理流程

```
setString(UTF-8)
  → 转换为 UTF-16 (_currentUTF16String)
  → 计算水平字距 (computeHorizontalKernings)
  → 为每个字符准备字形定义 (FontAtlas::prepareLetterDefinitions)
  → 记录每个字符的 LetterInfo (recordLetterInfo)
  → 计算行数 (computeStringNumLines)
  → 文本对齐 (alignText)
  → 更新四边形 (updateQuads)
```

## 3. Font 字体体系

### 3.1 类层次结构

```text
Ref
└── Font（抽象基类）
    ├── FontFreeType  →  FreeType 库渲染 TTF/OTF 字体
    ├── FontFNT       →  解析 AngelCode .fnt 格式的位图字体
    └── FontCharMap   →  固定宽度的字符映射纹理
```

### 3.2 Font 基类

**文件**：`cocos/2d/CCFont.h`

`Font` 是所有字体类型的抽象基类，继承自 `Ref`，定义了字体的核心接口：

```cpp
class Font : public Ref {
public:
    // 纯虚函数：创建字体图集

    // 将 UTF-8 文本转换为 UTF-16

    GlyphCollection _usedGlyphs;    // 当前使用的字形集合

```

**字形集合管理**：

- `_glyphASCII`：静态常量，包含完整的 256 个 ASCII 字符
- `_glyphNEHE`：静态常量，包含 94 个可打印 ASCII 字符（`!` 到 `~`）

- `setCurrentGlyphCollection()`：设置字形集合，根据 `GlyphCollection` 枚举选择对应的字符集

### 3.3 FontFNT（FNT 位图字体）

**文件**：`cocos/2d/CCFontFNT.h`

`FontFNT` 用于解析 AngelCode BMFont 格式的 `.fnt` 文件，支持多纹理页和字距表。

```cpp
class FontFNT : public Font {
public:
    static FontFNT* create(const std::string& fntFilePath, 
                           const Point& imageOffset = Point::ZERO);
    static void purgeCachedData();

    virtual int* getHorizontalKerningForTextUTF16(
        unsigned short *text, int &outNumLetters) const override;
    virtual FontAtlas* createFontAtlas() override;

protected:
    FontFNT(BMFontConfiguration *theConfig, const Point& imageOffset = Point::ZERO);
    virtual ~FontFNT();

        unsigned short firstChar, unsigned short secondChar) const;

    BMFontConfiguration* _configuration;  // 解析后的 FNT 配置

};
```

**FNT 文件格式解析**：

`BMFontConfiguration`（在 `CCFontFNT.cpp` 中定义）负责解析 `.fnt` 文件，其内部结构包括：

| 数据结构 | 说明 |
|----------|------|
| `tFontDefHashElement` | 字符定义：字符 ID、纹理坐标（x, y）、尺寸（width, height）、偏移量（xOffset, yOffset）、xAdvance、纹理页 |
| `tKerningHashElement` | 字距对：first(前字符) + second(后字符) 组合键 → amount(字距调整量) |
| `_fontDefDictionary` | 字符定义哈希表（key 为字符 ID） |
| `_kerningDictionary` | 字距对哈希表（key 为字符组合） |
| `_characterSet` | 当前字体支持的字符集 |
| `_commonHeight` | 公共行高 |
| `_atlasName` | 纹理图集文件名 |

**分页纹理支持**：FNT 格式支持多纹理页，每个字符定义包含 page 字段，`FontFNT` 在创建 `FontAtlas` 时会将不同页的纹理分别添加到图集中。

**字距计算**：`getHorizontalKerningForChars()` 通过查询 `_kerningDictionary` 获取两个字符之间的字距调整值。

### 3.4 FontCharMap（字符映射字体）

**文件**：`cocos/2d/CCFontCharMap.h`

`FontCharMap` 将字符图片按照固定宽高均匀分割，每个格子对应一个 ASCII 字符。

### 3.5 FontFreeType（FreeType 字体）

**文件**：`cocos/2d/CCFontFreeType.h`

`FontFreeType` 是基于 FreeType 库的字体渲染实现，支持 TTF 和 OTF 格式，提供距离场字体和描边功能。

- `shutdownFreeType()` 用于清理全局 FreeType 库

3. `renderCharAt()`：将位图数据复制到 `FontAtlas` 的纹理页缓冲区中

## 4. FontAtlas 字体图集

**文件**：`cocos/2d/CCFontAtlas.h`

`FontAtlas` 是字体图集管理器，负责将字形位图打包到纹理页中，并维护字形定义查找表。

### 4.1 FontLetterDefinition 字形定义

```cpp
struct FontLetterDefinition {
    unsigned short  letteCharUTF16;  // 字符的 UTF-16 编码
    float U;          // 纹理坐标 U（左上角）
    float V;          // 纹理坐标 V（左上角）
    float width;      // 字形宽度
    float height;     // 字形高度
    float offsetX;    // 水平偏移（用于对齐）
    float offsetY;    // 垂直偏移（用于对齐）
    int textureID;    // 纹理页 ID
    bool validDefinition;  // 是否为有效定义
    int xAdvance;     // 水平前进量（绘制下一个字符的 X 偏移）
    int clipBottom;   // 底部裁剪量
};
```

**字段说明**：

| 字段 | 说明 |
|------|------|
| `letteCharUTF16` | 字符的 UTF-16 编码，用作查找键 |
| `U, V` | 字形在纹理页中的左上角纹理坐标 |
| `width, height` | 字形在纹理页中的实际像素尺寸 |
| `offsetX, offsetY` | 字形绘制时的偏移量（用于基线对齐） |
| `textureID` | 所在的纹理页索引 |
| `validDefinition` | 标记该定义是否有效（未渲染的字符为 false） |
| `xAdvance` | 绘制完当前字符后，光标应前进的水平距离 |
| `clipBottom` | 底部裁剪量（用于紧凑布局） |

### 4.2 纹理页管理

```cpp
class FontAtlas : public Ref {
public:
    static const int CacheTextureWidth;   // 纹理页宽度（默认 512）
    static const int CacheTextureHeight;  // 纹理页高度（默认 512）
    static const char* EVENT_PURGE_TEXTURES;  // 清除事件名

    FontAtlas(Font &theFont);
    virtual ~FontAtlas();

    // 添加字形定义
    void addLetterDefinition(const FontLetterDefinition &letterDefinition);

    // 查询字形定义
    bool getLetterDefinitionForChar(unsigned short letteCharUTF16, 
                                    FontLetterDefinition &outDefinition);

    // 预准备字形定义（为给定字符串中的所有字符生成字形）
    bool prepareLetterDefinitions(unsigned short *utf16String);

    // 纹理管理
    const std::unordered_map<ssize_t, Texture2D*>& getTextures() const;
    void addTexture(Texture2D *texture, int slot);
    Texture2D* getTexture(int slot);

    // 行高
    float getCommonLineHeight() const;
    void  setCommonLineHeight(float newHeight);

    // 获取关联的 Font 对象
    const Font* getFont() const;

    // 清除纹理图集

    // 纹理参数设置
    void setAntiAliasTexParameters();  // 线性过滤（抗锯齿）
    void setAliasTexParameters();      // 邻近过滤（无抗锯齿，像素风格）

```

**纹理图集结构**：

- `_atlasTextures`：`std::unordered_map<ssize_t, Texture2D*>`，key 为纹理页索引，value 为纹理对象
- `_fontLetterDefinitions`：`std::unordered_map<unsigned short, FontLetterDefinition>`，key 为 UTF-16 字符码，value 为字形定义
- `_currentPage`：当前正在写入的纹理页索引
- `_currentPageData`：纹理页原始像素数据缓冲区
- `_currentPageOrigX, _currentPageOrigY`：当前纹理页的写入光标位置
- `_letterPadding`：字形之间的间隔填充

**纹理页常量**：

```cpp
static const int CacheTextureWidth = 512;   // 纹理页宽度（像素）
static const int CacheTextureHeight = 512;  // 纹理页高度（像素）
```

### 4.3 字形缓存与动态加载

**`prepareLetterDefinitions()`** 是核心方法：

1. 遍历传入的 UTF-16 字符串
2. 对每个字符，先检查 `_fontLetterDefinitions` 中是否已有定义
3. 若无定义，调用 `Font::createFontAtlas()` 获取字形位图
4. 将字形位图写入当前纹理页（`_currentPageData`）
5. 若当前纹理页已满，创建新纹理页（`addTexture()`）
6. 将字形定义存入 `_fontLetterDefinitions`

**动态字形集合（DYNAMIC）**：当使用 `GlyphCollection::DYNAMIC` 时，字形按需生成。首次渲染某个字符时，`FontFreeType` 会实时渲染该字形，然后由 `FontAtlas` 将其打包到纹理页中。

**前后台切换**：在 Android 平台上，OpenGL 上下文可能在应用切换到后台时丢失。`FontAtlas` 通过注册 `EVENT_PURGE_TEXTURES` 事件监听器，在回到前台时自动重建纹理图集。

### 4.4 纹理过滤模式

- **`setAntiAliasTexParameters()`**：设置 `GL_LINEAR` 过滤，平滑显示，适合大多数场景
- **`setAliasTexParameters()`**：设置 `GL_NEAREST` 过滤，像素风格，适合像素字体

## 5. FontAtlasCache 字体图集缓存

**文件**：`cocos/2d/CCFontAtlasCache.h`

`FontAtlasCache` 是全局字体图集缓存管理器，采用单例模式（静态方法），避免重复创建相同配置的 `FontAtlas`。

### 5.1 缓存策略

```cpp
class FontAtlasCache {
public:
    static FontAtlas* getFontAtlasTTF(const TTFConfig &config);
    static FontAtlas* getFontAtlasFNT(const std::string& fontFileName,
                                       const Point& imageOffset = Point::ZERO);
    static FontAtlas* getFontAtlasCharMap(const std::string& charMapFile,
                                           int itemWidth, int itemHeight, int startCharMap);
    static FontAtlas* getFontAtlasCharMap(Texture2D* texture,
                                           int itemWidth, int itemHeight, int startCharMap);
    static FontAtlas* getFontAtlasCharMap(const std::string& plistFile);

    static bool releaseFontAtlas(FontAtlas *atlas);
    static void purgeCachedData();

private:
    static std::string generateFontName(const std::string& fontFileName, int size,
                                         GlyphCollection theGlyphs, bool useDistanceField);
    static std::unordered_map<std::string, FontAtlas*> _atlasMap;
};
```

**缓存键生成**：`generateFontName()` 根据字体文件名、大小、字形集合和距离场标志生成唯一键名，格式为 `"fontName_size_glyphs_distanceField"`。

**缓存流程**：

1. **获取**：调用 `getFontAtlasTTF()` / `getFontAtlasFNT()` / `getFontAtlasCharMap()` 时，先根据配置生成键名，在 `_atlasMap` 中查找
2. **命中**：直接返回已缓存的 `FontAtlas`
3. **未命中**：创建新的 `Font` 对象（`FontFreeType` / `FontFNT` / `FontCharMap`）→ 调用 `Font::createFontAtlas()` → 存入 `_atlasMap` → 返回
4. **释放**：`releaseFontAtlas()` 减少引用计数，当引用计数降为 1 时从缓存中移除

**清除缓存**：`purgeCachedData()` 会清除所有缓存的 `FontAtlas` 对象，通常在场景切换或内存紧张时调用。

## 7. 迁移指南

### 7.1 从 LabelTTF 迁移到 Label

| 旧 API（LabelTTF） | 新 API（Label） |
|---------------------|-----------------|
| `LabelTTF::create(text, fontName, fontSize)` | `Label::createWithSystemFont(text, fontName, fontSize)` |
| `LabelTTF::create(text, fontFile, fontSize, dims, hAlign, vAlign)` | `Label::createWithTTF(text, fontFile, fontSize, dims, hAlign, vAlign)` |
| `labelTTF->setString(text)` | `label->setString(text)` |
| `labelTTF->setFontSize(size)` | 使用 `setTTFConfig()` 或重建标签 |
| `labelTTF->setFontName(name)` | `label->setSystemFontName(name)` |
| `labelTTF->setDimensions(size)` | `label->setDimensions(width, height)` |
| `labelTTF->enableShadow(offset, opacity, blur)` | `label->enableShadow(Color4B, offset, blurRadius)` |
| `labelTTF->enableStroke(color, size)` | `label->enableOutline(Color4B, size)` |

### 7.2 从 LabelBMFont 迁移到 Label

| 旧 API（LabelBMFont） | 新 API（Label） |
|-----------------------|-----------------|
| `LabelBMFont::create(str, fntFile, width, align)` | `Label::createWithBMFont(fntFile, str, align, width)` |
| `labelBMFont->setString(str)` | `label->setString(str)` |
| `labelBMFont->setFntFile(fntFile)` | `label->setBMFontFilePath(fntFile)` |
| `labelBMFont->setAlignment(align)` | `label->setHorizontalAlignment(align)` |
| `labelBMFont->setWidth(width)` | `label->setMaxLineWidth(width)` |

### 7.3 从 LabelAtlas 迁移到 Label

| 旧 API（LabelAtlas） | 新 API（Label） |
|----------------------|-----------------|
| `LabelAtlas::create(str, charMapFile, w, h, start)` | `Label::createWithCharMap(charMapFile, w, h, start)` |
| `LabelAtlas::create(str, fntFile)` | `Label::createWithCharMap(plistFile)` |

### 7.4 迁移注意事项

1. **参数顺序变化**：新 API 的参数顺序与旧 API 可能不同，注意核对。例如 `LabelBMFont::create()` 是先 `str` 后 `fntFile`，而 `Label::createWithBMFont()` 是先 `fntFile` 后 `str`。
2. **Model 类型变化**：旧 `LabelTTF` 继承自 `Node`，新 `Label` 继承自 `SpriteBatchNode`。如果代码中使用了 `dynamic_cast<LabelTTF*>` 或类似依赖继承关系的操作，需要相应调整。
3. **特效 API 差异**：
   - 旧 `LabelTTF` 的 `enableShadow()` 接受 `float shadowOpacity`，新 `Label` 的 `enableShadow()` 接受 `Color4B`（包含 Alpha 通道）
   - 旧 `LabelTTF` 的 `enableStroke()` 已被 `enableOutline()` 替代
   - 新 `Label` 的描边和发光效果仅 TTF 类型支持
4. **字体大小变更**：旧 `LabelTTF` 可以在运行时通过 `setFontSize()` 动态修改字体大小，新 `Label` 需要通过 `setTTFConfig()` 重新设置配置来改变字号。
5. **性能考虑**：新 `Label` 的 `setString()` 在 TTF/BMFont/CharMap 配置已设置的情况下性能较好；如果未设置字体配置，`setString()` 相当于创建新标签，开销较大。

## 8. 注意事项与最佳实践

### 8.1 性能优化

1. **预设置字体配置**：在调用 `setString()` 之前先调用 `setTTFConfig()` / `setBMFontFilePath()` / `setCharMap()`，避免每次 `setString()` 都重建字体配置。

2. **选择合适的字形集合**：
   - 英文界面使用 `GlyphCollection::NEHE`（94字符）或 `ASCII`（256字符），比 `DYNAMIC` 更高效
   - 中文界面使用 `GlyphCollection::DYNAMIC`，按需加载避免一次性生成大量字形
   - 固定文本使用 `CUSTOM` + `customGlyphs`，可以精确控制字形数量

3. **批量更新**：修改多个属性后调用一次 `updateContent()`，避免每次修改都触发重绘。

4. **BMFont 优于 CharMap**：BMFont 支持可变宽度字符和字距，视觉效果更好；CharMap 适合简单的等宽数字显示。

5. **避免频繁 setString**：频繁改变文本内容时，优先使用 BMFont 类型（字形已预生成），TTF 类型每次可能触发新的字形生成。

### 8.2 内存管理

1. **FontAtlas 缓存**：相同配置的字体自动共享 `FontAtlas`，避免创建重复的纹理图集。
2. **清除缓存**：场景切换时调用 `FontAtlasCache::purgeCachedData()` 释放不再使用的字体图集。
3. **纹理页大小**：默认 `CacheTextureWidth × CacheTextureHeight = 512 × 512`，对于大量中文字形，可能产生多个纹理页。可以通过调整常量来优化。
4. **距离场字体**：距离场字体可以在一个较小的纹理页中支持多种字号，适合需要多字号显示的 UI 系统。

### 8.3 字体文件路径

1. **TTF 字体文件**：将 `.ttf` 或 `.otf` 文件放在 `Resources/fonts/` 目录下，通过 `FileUtils::getInstance()->fullPathForFilename()` 解析路径。
2. **系统字体**：使用 `createWithSystemFont()` 时，`font` 参数可以是系统字体名称（如 `"Arial"`、`"SimSun"`），不同平台可用的字体名称不同。
3. **FNT 文件**：确保 `.fnt` 文件和对应的 `.png` 纹理文件在同一目录下。

### 8.4 文本编码

1. **UTF-8 编码**：`setString()` 接受 UTF-8 编码的字符串，内部自动转换为 UTF-16 处理。
2. **多语言支持**：FreeType 字体支持 Unicode 字符集，可以显示中文、日文、韩文等多字节文字。
3. **不支持的字符**：如果字体文件中不包含某个字符的字形，该字符将显示为空白或占位符。

### 8.5 特效使用

1. **阴影与描边互斥**：同一时间只有一个特效生效（`_currLabelEffect`），`enableShadow()` 和 `enableOutline()` 会互相覆盖。
2. **描边与距离场互斥**：`TTFConfig` 中 `outlineSize > 0` 会强制禁用 `distanceFieldEnabled`。
3. **描边开销**：描边需要 FreeType 的 `FT_Stroker` 额外计算，字形生成成本增加。
4. **阴影模糊**：当前 `enableShadow()` 的 `blurRadius` 参数标记为 `@todo`，暂未实现模糊效果。

### 8.6 平台差异

1. **Android 前后台切换**：`FontAtlas` 注册了 `EVENT_PURGE_TEXTURES` 事件，在应用回到前台时自动重建纹理。这是 Android 平台的必需行为（OpenGL 上下文可能丢失）。
2. **系统字体可用性**：不同平台的系统字体列表不同，`createWithSystemFont()` 的 `font` 参数需要根据平台选择合适的字体名称。
3. **FreeType 初始化**：`FontFreeType` 的 `_FTlibrary` 是全局静态变量，在多线程环境中需要注意线程安全。

### 8.7 兼容性

1. **旧代码兼容**：`LabelTTF` 和 `LabelBMFont` 虽然标记为废弃，但内部委托给新 `Label`，功能正常可用。建议新代码直接使用 `Label`。
2. **LabelAtlas**：未被标记为废弃，但 `Label::createWithCharMap()` 提供了更一致的接口。
3. **废弃 API**：`Label::create()` 旧版重载和 `setFontDefinition()` 已标记 `CC_DEPRECATED_ATTRIBUTE`，不应在新代码中使用。
